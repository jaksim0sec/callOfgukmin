# 국민의 부름 — 출생 지역 분류 사전 (기획용)

> 기준일: 2026-10-19 · **출생 시스템 설계 자료, 게임 미구현** · 현재의 행정구역과 창작 태그를 구분한다.
>
> **17개 기획 권역 · 3개 대표 생활/행정권씩 · 5개 세부 지역씩 = 255개 출생 후보**. 이는 전국 모든 행정구역의 완전한 목록이 아니라 시나리오 표본이다.

## 조회 규칙

- 키: **`시도.시군구.읍면동`**. 구가 있는 시에서는 **`시도.시.구.동`**. 이 점(.) 구분 경로를 출생 기록의 고유 식별자로 쓴다. 예: `경기도.성남시.분당구.정자동`.
- 태그: 공백으로 나뉜 `#도시 #수도권 #학군지` 같은 검색 키워드. **`#수도권`**은 서울·인천·경기에만 적용. 나머지는 **`#지방`**으로 구분한다.
- 분류: `#도시`, `#농촌`, `#어촌`, `#산업`, `#항만`, `#신도시` 등은 **게임 사건 필터를 위한 생활환경 태그**다. 행정상 지정된 공식 유형이나 모든 주민의 생활을 뜻하지 않는다.
- 교육환경: `#학군지`는 기획상 통용되는 생활권 이미지다. 학교의 공식 등급·입시 성적·지역 주민의 역량을 의미하지 않으며 실제 통계 검증 전에는 게임상 효과/가중치로 사용하지 않는다.
- **대표 시·군·구 3개**를 권역마다 선별했으며 하위 지역은 정확히 5개씩 수록했다. 실제 시에 자치구가 5개 없는 경우 **읍·면·동**으로 내려간다. 서울 등 광역시는 구·군 자체가 표본의 대표 단위다.
- **세종**은 하위 기초자치단체 3개가 없으므로 3개 **생활권**으로 분류한다. **제주**도 실제 행정시가 2개뿐이어서 제주시를 도시/읍면으로 나눠 3개 생활권으로 묶는다. 생활권 이름은 **게임상의 구획**이지 법정 행정단위가 아니다.
- **2026-07-01 행정개편 반영:** 광주광역시와 전라남도는 현재 `전남광주통합특별시`로 통합되었지만, 과거 17개 시도 설계와 출생 서사 호환을 위해 **'광주권' / '전남권'을 별도 기획 그룹**으로 유지했다. 두 그룹의 키는 모두 현행 광역단위 `전남광주통합특별시`로 시작한다. 옛 광주광역시·전라남도 경로를 정식 주소로 취급하지 않는다.
- **2026-07-01 인천 개편 반영:** 영종구, 제물포구, 검단구, 서해구 등 변경된 구 체계를 기준으로 하며 영종구를 표본에 포함했다.
- 부모 재력은 출생지 태그와 **별도 차원**이다. `지역 × 가구 순자산 계층 × 소득/직업 배경`의 조합을 생성하되 태그만으로 소득·정치 성향·학업 능력을 결정하지 않는다.

### 검색 예시

- `경기도.성남시.분당구.정자동` → `#수도권 #도시 #학군지`
- `경상북도.포항시.남구.구룡포읍` → `#지방 #어촌 #항만`
- `전남광주통합특별시.광산구.수완동` → `#지방 #광주권 #신도시 #학군지`

## 다음 기획에서의 사용

1. 사용자는 별도의 지역 선택 없이 출생한다. 출생 후보는 `지역 그룹 → 기초권역 → 세부 지역`에서 선정한다. **추첨 확률과 연도별 출생아 규모는 이 사전에 포함하지 않는다.**
2. 부모 순자산 계층(흙수저~다이아수저)과 부모 소득·직업을 **별도로 추첨·조건 조정**한다. 예: `#어촌`이면 어업 관련 직업·해양 사건이 후보에 오르되 반드시 어업 가정으로 태어나는 것은 아니다.
3. 사건 작성 시 `#어촌`, `#농촌`, `#산업` 태그를 조건으로 사용할 수 있게 기획한다. 여러 조건이 겹치면 우선순위나 확률을 추후 지정한다.
4. 공식 주소 데이터로 실제 행정구역명, 개편 사항, 행정동/법정동 정합성을 **구현 전 전수 검증**한다. 이 문서는 후보지 카탈로그이며 주소 코드 목록의 공식 인증본은 아니다.
