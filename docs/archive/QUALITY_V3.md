# 품질 점검 — 국민의 부름 v3

> **과거 검증 기록**: 이번 정리에서 재검증된 결과가 아니다. [RUNTIME.md](../developing/RUNTIME.md) 참조.

## 핵심 작동 테스트

- 게임 시작, 매 스테이지의 일상 선택 → 결과 표시 → 다음 행동 → 전용 한방 선택 → 다음 스테이지 연결
- 15개 생애 스테이지와 조건부 비정치 루트 모두 종료 가능
- 29종 랜덤 이벤트, 지연 효과, 스펙트럼 변화, 정당별 색상 및 적합도 계산
- 가상 정당 5개 및 무소속 선택 가능
- 정치 경력의 지역선거·국회·대선 경선, 제명 및 법적 책임 등 분기
- 후보 지명 성공 후 공약/최종 유세/대선 개표
- 저장 데이터에서 진행 재개, 새 인생 초기화
- 결과 카드 PNG 출력 경로, 이름·기호·토큰 UI 참조 점검

## 자동화 검증

- `game.js` 문법 확인: JavaScript 구문 검사
- DOM ID와 자바스크립트 참조 정합성 확인
- 가짜 DOM·로컬 저장소와 클릭 콜백을 이용해 수백 건의 랜덤 인생을 엔딩까지 자동 진행
- 선거 승패, 제명, 감옥, 직업 엔딩에 도달 가능한지 확인
- **수동 브라우저 화면 점검은 별도**이며, 자동 재생 성공이 실제 모바일의 디자인/터치 사용성을 보장하지는 않는다.

## 범위와 제약

- 이번에는 대통령 **당선 발표까지**, 임기·탄핵·재선 미포함
- 가상 정당/번호/정치 성향/여론조사/선거/인생 사건은 창작
- 교육·자격 제도도 게임 흐름을 위해 단순화
- 8개 캐릭터 모델을 위한 상태 슬롯만 생성. 실제 얼굴 일러스트는 차기 작업
- 실제 브라우저별 CSS `color-mix` 호환성, Canvas에서 한글 폰트 준비 등은 실기기 검수 필요
- 창작 정치 풍자라 하더라도 법률상 면책이 보장되지는 않는다
