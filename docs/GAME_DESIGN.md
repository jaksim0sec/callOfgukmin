# 대학의 부름 — 게임 설계 기준 (2026-11-14)

> **상태: 기획 기준 확립, 신규 게임 미구현.** 이 문서는 개편 목표와 초안을 구분한다. 현재 플레이 가능한 코드는 여전히 「국민의 부름」이다. 실제 구현 계약은 [developing/](developing/)의 기존판 설명과 소스로 확인한다.

## 1. 합의된 방향

- **정식 게임명: 대학의 부름**. 저장소 `jaksim0sec/callOfgukmin`의 리브랜딩이지만 저장소/배포 URL 변경은 현재 범위가 아니다.
- **장르/초점: 한국 입시를 풍자하는 짧은 선택형 미니게임**. 대학 진학 자체보다 입시를 둘러싼 불합리한 선택 구조와 그 결과가 재미의 원천이다.
- 대통령 당선이나 장기 정치 인생은 **더 이상 본편 목표가 아니다**.
- 기존의 학생기·시험·수시/정시·N수 구현을 출발점으로 삼고, 구조를 먼저 줄여서 재사용한다. 기능을 무작정 추가하는 개편이 아니다.
- **이번 단계는 문서 개편**이다. 새 메커니즘, 엔딩, UI, 저장 키가 구현되었다고 쓰지 않는다.

## 2. 핵심 경험

플레이어는 정답 없는 입시 환경에서 **정보가 불완전한 선택**을 한다. 내신을 택하면 수능에 투자할 시간이 줄고, 생기부를 채우면 공부나 인간관계를 희생한다. 특정 제도의 허점으로 이득을 볼 수도 있고, 예상치 못한 평가 방식과 경쟁 변화로 전략이 흔들릴 수도 있다.

**풍자의 대상은 입시 시스템과 경쟁 구조**이지 학생 개인, 특정 성적대, 가정형편, 실패 경험이 아니다. 과장된 장면이라도 왜 그런 결과가 나왔는지 사후에는 이해할 수 있어야 한다.

### 풍자 소재와 사건 방향

| 소재 | 장면 예시 (미확정) | 플레이어가 결정하는 것 |
|---|---|---|
| 내신 vs 수능 | 모의고사에 올인한 사이 수행평가가 연달아 몰림 | 단기 시험 고점과 학기 누적 성적의 교환 |
| 생기부와 스펙 | 동아리 활동보다 그 활동을 설명할 문서가 더 바빠짐 | 활동, 기록, 공부 시간을 어디에 쓸지 |
| 정보 격차 | 같은 입시 공고를 보고도 얻는 정보의 양이 다름 | 상담·정보 탐색 비용과 확실성 |
| 제도와 경쟁 변화 | 바뀐 평가표가 기존 전략을 무력화하는 듯 보임 | 기존 계획을 유지할지 전환할지 |
| 수시·정시 | 안정 지원인지, 상향 도전인지, 다른 전형인지 | 한정된 지원 기회의 분배 |
| N수 | 한 번 더 준비하면 나아질 수도 있지만 기회비용이 늘어남 | 재도전과 이번 판 종료 사이 선택 |

위 사례는 **콘텐츠 초안**이다. 실제 학생에게 적용되는 입시 정보나 공인 대학 합격률로 취급하지 않는다. 특정 대학·집단에 대한 허위 사실을 풍자 장치로 단정하지 않는다.

## 3. 한 판의 흐름 (구현 전 가설)

`시작 조건/환경 확인 → 학기 단위 전략 선택 → 돌발 사건과 성적·이력 정산 → 수능 및 지원 전략 → 합격 결과/회고 → 선택적 재도전`

- **시작 구간:** 고1 시작을 우선 실험해 보되, 기존 출생·초·중학교 서사를 초반 요약이나 초기 조건으로 압축할지는 아직 미정이다.
- **진행:** 학기·시험·원서 등 의미 있는 결정만 남겨 짧게 구성한다. 일상 선택과 한방 선택의 차이는 유지할 수 있다.
- **종료:** 대학 지원의 결과와 플레이어가 거쳐 온 선택을 함께 보여 준다. 특정 대학 합격만이 유일한 성공/실패 판단이 되지 않도록 한다.
- **N수:** 재도전의 풍자적 역할은 살리되, 기존 30세까지 이어지는 장기 인생 루프는 그대로 가져오지 않는다.
- **목표 플레이 시간:** 한 판 약 5~10분은 초기 제안이며 실제 플레이 테스트 후 확정한다.

## 4. 최소 시스템 방향 (수치 미확정)

1. **기존 수치 우선:** `schoolScore`(내신), `exam`(시험), 관계, 압박, 재산, 특성·이력 등을 먼저 재검토한다. 새 스탯 생성은 기존 기록·선택으로 표현하기 어렵다는 근거가 있을 때만.
2. **생기부는 활동/이력 중심:** 미확정 단일 '생기부 점수'를 무작정 추가하지 않는다. 기존 활동 이력으로 평가가 가능한지 우선 조사한다.
3. **선택은 실제 비용이 있어야 함:** 선택지 수를 늘리는 대신 투자, 포기, 불확실한 보상을 명확히 설계한다.
4. **운은 예측의 불완전함:** 플레이어가 아무것도 통제할 수 없는 뽑기 게임으로 만들지 않는다. 같은 시드/저장 상태에서 결과를 새로고침으로 바꾸지 않는 기존 규칙을 우선한다.
5. **사건은 후폭풍을 남김:** 처음 선택이 학기 말·원서 시기에 조건과 반응으로 돌아오게 한다. 모든 사건을 개별 거대 시스템으로 만들지 않는다.
6. **엔딩은 풍자의 결산:** '좋은 대학'을 절대 점수화하기보다 선택의 궤적·제도적 아이러니·지원 결과를 보여 준다.
