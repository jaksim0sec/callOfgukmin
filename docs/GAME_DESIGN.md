# 국민의 부름 — Game Design v3

> **설계 변경 기록 (2026-10-19):** 이 문서는 이전 **v3 설계 이력**이다. 현재 플레이 가능한 시연판과도 다를 수 있다. 후속 스탯 변경 논의는 [STATS.md](./STATS.md), 차기 스탯 토큰 UI는 [UI_REDESIGN.md](./UI_REDESIGN.md)의 끝부분을 참조한다. 기존의 '여섯 능력치'·'2차원 정치 스펙트럼'은 새 8개 스탯 논의안과 충돌하며, 자동 병합하거나 새 사양으로 오인하지 않는다.

## 게임 목표

게임 진행시간은 약 5~10분이지만, 시스템은 단선형 설문지가 아니라 자원·상태·경로·상황의 상호작용으로 구성한다. 대통령 당선뿐 아니라 다른 인생의 결말도 온전한 엔딩이다.

## 두 가지 종류의 선택

| 종류 | 특징 | 화면 |
|---|---|---|
| 일상 선택 | 매 단계 1~2번. 무작위 사건에서 제시되는 상황별 행동 3개 + 개인 활동 1개 | 게임 보드 안 선택 카드 |
| 한방 선택 | 인생을 분기하는 사건. 다음 단계로 넘어가며 진로·직업·소속/후보자 지위가 변동 | 전용 서류형 모달. 입당 시 가상 투표지 |

학업 단계에서 고교 유형과 진학, 대학원 진학, 첫 직업, 사회 활동, 정치 참여와 정당을 직접 선택. 정치 경로를 거절하면 선출직 없이 다른 인생으로 이어진다.

## 인생의 진행

- 15개 생애 스테이지: 5세~60세, 가상 연도 흐름.
- 출생지는 대한민국 지역 중 하나를 랜덤으로 사용하나 정치적 유불리는 평가하지 않음.
- `FAMILY`의 무작위 출생 배경과 `state.seed`에 따른 사건·결과 확률이 다회 플레이를 다르게 만듦.
- 총 29종 랜덤 일상 사건은 학창·진로·사회·정치·선거 캠페인으로 나뉨. 출현 가능한 사건만 제시하며 한 생애 중 선택했던 사건은 가급적 반복하지 않음.
- 행동 기록은 지연 효과를 예약할 수 있음. 옛 영상/계약/사업/동료/주민 활동 등이 2~3 스테이지 뒤 재등장.
- 이력과 조건에 따라 일상 선택, 선거 결과, 정당 신뢰, 최종 인생 분기가 달라짐.

## 여섯 가지 게임 능력치

`skill` 역량, `network` 인맥, `money` 자금, `fame` 인지도, `trust` 신뢰, `risk` 논란. 0~100의 창작 게임 수치. 실제 학력·직업의 서열이나 정치 여론조사 자료가 아님.

## 정치 스펙트럼: 2차원

`econ`: -100 분배 중심 ↔ +100 시장 중심.
`change`: -100 빠른 변화 ↔ +100 안정 중심.
입당 이전에도 정책/동아리/지역사회 발언에 따라 서서히 형성되며, 정치 전문 용어를 몰라도 선택지에 '분배 중시' 같은 쉬운 토큰을 붙여서 이해할 수 있게 함.

가상의 5개 정당은 각각 기준 좌표, 게임상 자원 보정, 고유 색상·기호·슬로건을 가짐. 특정 사상에 일률적인 우월/열등·범죄성을 부여하지 않음.

정당 입당 시 출발 충성/소속당 신뢰도는 플레이어 성향과 정당 간 거리로 결정. 입당 이후 기준점에서 크게 벗어나는 방향의 주장을 반복하면 소속당 신뢰가 하락하고 일정 이하로 떨어지면 제명·정치 종료 엔딩. 선거 확률 계산은 지식·인맥·돈·인지도·대중 신뢰·논란·정당 적합성을 반영한다.

## 선거 분기

- 지역 선거: 출마 혹은 캠프/지역 활동 지속, 일정 확률로 승패.
- 국회의원 선거: 선거 출마/정책위원/지역정치/은퇴.
- 대통령 후보 경선: 정책·조직·SNS 중 선택, 실패하면 경선 탈락 엔딩.
- 후보 지명 성공 시: 대표 공약 선택, 캠페인 중 랜덤 일상, 최종 유세, 가상 선거 개표.
- 가상 전국 예측은 6개 **허구 지역권**으로 표시. 실제 수도권·영호남 지지율이나 현실 후보 관련 편향 자료를 반영하지 않음.
- 모든 투표율은 게임 밸런스와 랜덤 요인에서 계산. 대통령 후보 경선과 실제 등록절차는 간략화. 대통령 임기/탄핵/재선은 다음 범위.

## 엔딩

대통령 당선 / 대선 낙선 / 경선 탈락 / 정당 제명 / 법 위반 유죄 판결 / 사업 성취 / 정치 방송 유명인 / 지역 정치인 / 분야 전문가 / 취업과 재도전 / 평범한 삶.

유죄 엔딩은 가상의 본인 부정거래와 은폐 행위 기록이 쌓인 경우에만 발생하며 특정 이념, 정당, 학력 선택에 결부되지 않는다. 단순 의혹만으로 유죄가 확정되는 게임이 아님.

## 코드 엔진 분리 원칙

- `POOLS`: 일상 사건 데이터
- `MAJORS`: 한방 선택 및 전용 문서 이름
- `shiftStance`: 스펙트럼 이동·소속당 반응
- `state.pending`: 지연된 선택 후폭풍
- `lifeNickname` / `slogan`: 상황별 인물 포스터 타이틀
- `renderPoster` / `renderGame` / `renderEnd`: UI 파생
- `posterBlob`: 로컬 Canvas 공유 이미지

UI는 이벤트를 단순히 텍스트로 나열하는 방식을 피하고 게임 보드 / 상태벽보 / 문서형 인생 결정 / 타임라인으로 구획한다.
