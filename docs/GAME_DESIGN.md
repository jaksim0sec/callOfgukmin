# GAME_DESIGN — 국민의 부름 v1

기준일: 2026-10-19. 오리지널 가상 정치 풍자 게임이며 현실 선거 전망과 무관.

## 목표 및 플레이 길이

한 번의 인생을 선택하고 대선 당선 또는 실패·다른 삶의 엔딩 카드까지 약 5~10분.
게임 진행은 인생으로서 완결되며, 대통령 취임 이후 국정 운영·탄핵·재선은 후속 버전 대상으로 제외한다.
플레이어가 대선 후보가 되지 않아도 게임은 온전한 결말을 제공한다.

## 진행 구조

- 출생과 성장: 랜덤 출생 지역·가정 배경, 학교 유형, 청소년 활동
- 학업과 생업: 진학·재수·직업 선택, 직장생활 및 사업
- 사회 활동: 지역 문제·관계·논란의 원인이 되는 선택
- 정치 입문: 캠프 합류, 정책 자문, 정계 포기, 지역 선거
- 정당·공천: **5개 가상 정당의 투표용지풍 UI**, 정당별 조직력과 공약 궁합
- 대선 도전: 국회의원 선거, 대선 경선, 공약 발표, TV토론, 개표
- 결과 카드: 이름·엔딩·학교·당·성공과 실수·선거 득표율(해당 시)

각 장면은 3~5개 선택지. 결과는 스탯·난수·기존 이력에 영향받고, 장면별 추후 상황에도 흔적을 남긴다.

## 스탯

실력·인맥·자금·인지도·신뢰·논란 위험도 0~100. 실력 등의 숫자는 학교나 지역의 실세계 가치가 아닌 **게임의 자원**.
플레이 초반에 '지지율'을 노출하지 않고, 인생 중반 이후에 정치 입지와 전체 진행 단계를 보여준다.
'득표율'은 마지막 개표에서만 창작 점수로 산출하고, 대통령 후보 자격이 없는 경로에는 표시하지 않는다.

## 가상 정당

| 기호 | 정당 | 기본 성향 | 게임상 특징 |
|---|---|---|---|
| 1 | 자유국민당 | 안정·산업·질서 | 조직과 자금 ↑ |
| 2 | 민주혁신당 | 민생·복지·개혁 | 신뢰와 인맥 ↑ |
| 3 | 민생직진당 | 빠른 재분배 | 인지도 ↑ / 자원 부담 |
| 4 | 철벽수호당 | 안보·전통 | 조직·정책 전문성 ↑ |
| 5 | 실용미래당 | 실용·절충 | 실력·신뢰 ↑ / 인지도 도전 |

실제 정당의 명칭·로고·전용 상징을 사용하지 않으며, 가상 번호는 법정 기호가 아니다.
당을 고르자마자 현실 정치 인물을 평가하거나 특정 진영을 정답으로 표현하지 않는다.

## 게임오버

정치 포기 후 일반 직업인, 사업가, 정치 논객, 지역 정치인, 참모, 경선 탈락, 대선 낙선, 대통령 당선 등 분기.
부정행위 후 책임을 회피한 선택이 누적되면 형사 절차가 끝난 엔딩도 가능하다.
단순히 정당 소속이나 특정 학교를 골랐다는 이유만으로 법적 제재나 몰락을 일으키지 않는다.

## 공유 및 저장

로컬 자동 저장: localStorage, 유효성 검사 후 로딩.
결과 카드: 브라우저 Canvas에서 직접 PNG 생성 (외부 업로드 없음). Web Share API 우선, 불가능하면 텍스트 공유.
시작 화면, 선택 카드, 결과 카드가 다양한 모바일 해상도에서 이해되도록 반응형 CSS.

## 구조 및 유지보수

의존성 없는 `index.html`, `style.css`, `game.js` 정적 웹 앱.
선택 데이터는 JS 내부 스테이지 데이터에서 관리하며 상태/저장/UI/결과화면을 함수별로 분리.
변경 시 필수 회귀: 5개 정당 중 어느 것이든 선택 → 후보 등록/경선 → 승패 / 비정치 엔딩 → 저장·새로고침 복구 / 결과 이미지.
