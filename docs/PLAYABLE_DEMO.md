# 시연 작동판 v4 — 검증 및 설계 경계

## 출처와 우선순위

1. 사용자가 직접 작성한 초경량 HTML 시연: 정치 포스터, 나이, 학교·경력 토큰, 능력치, 인생 기록.
2. 사용자가 첨부한 다듬어진 HTML 시연: PC 3열 인물 상태, 모바일 고정 바텀시트, 이벤트 타임라인, 학교 교표/직업 명함/가상 투표지 팝업.
3. 사용자 승인한 학교 선택 모달: 문서형 제목, 선택 카드·선택 효과 토큰, 어두워지고 블러되는 뒷배경, 아래에서 올라오는 전환.

**디자인을 이 파일들에 영구 고정한다는 뜻이 아님.** 다음 작업은 하나씩 피드백받아 변경.

## 현재 동작

- 시작 시 출생 배경·특성·초기 능력치 랜덤.
- 인생 기록에서 사건 설명을 먼저 읽고 나서 선택지를 열음.
- 학교의 자격조건 검증, 대학 지원, 직업, 정당 입당, 공개 발언, 선거 분기.
- 정당마다 가상 정치 방향과 테마 색상. 정치 노선 불일치 시 신뢰 하락/제명.
- 성적·정신력·지지도·자산·인맥·1차원 정치 스펙트럼.
- 경험·특성에 따른 일부 후속 이벤트 보정 및 지연된 계약 논란.
- 브라우저 로컬 저장/복구, 새 인생, PNG 엔딩 카드 다운로드.

## 검증

- 실제 Chromium에서 PC 1366x768, 모바일 390x844 렌더링 및 학교 5개 카드·토큰·지원 UI 확인.
- 여러 무작위 경로를 처음부터 엔딩까지 자동 진행해 브라우저 자바스크립트 예외 여부 확인.
- 후보 경선 실패, 대선 당선/낙선, 당내 제명, 후원금 관련 법적 책임 등 결과 도달 확인.
- 실제 모바일 기기에서 터치 사용감과 글꼴 환경 검수는 사용자 피드백이 필요.

## 의도적으로 보류한 것

- 8개 캐릭터 모델과 나이별 정식 일러스트, 상황별 배경 이미지 대량 제작.
- 대통령 당선 후 임기·탄핵·재선.
- 정치 성향의 다축 심화, 직업별 장기 상태 관리 및 수많은 실제 사건.
- 최종 디자인 시스템 고정, 모든 화면을 이 시연 형식에 강제하는 작업.
