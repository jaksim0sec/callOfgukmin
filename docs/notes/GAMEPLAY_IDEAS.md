# 생애 진행·선택 시스템 구상

> **2026-10-21 현행과 구분:** 이 초기 아이디어 중 소식/일상/한방, 학생/입시, 수시·정시와 1회 재도전은 구현됐다. **일상 선택을 인생 기록 아래 버튼으로 표시·한방 전용 UI 미구현**은 당시의 개발 상태다. 지금은 일상 모눈종이·동일 시트 보상과 한방 시험·학교·대입 모달이 있다. 대학 생활·성인·정치·무제한 N수는 아직 구상이다.

> 사용자 기획 요청 기록(2026-10-19). **클로드의 전체 방향성 제안이 아직 도착하지 않은 미확정 상태**. 구현 지시 아님.

## 선택의 위계
- **일상 선택:** 보통 작은 능력치·자원 변화. 일부는 의외로 훗날 큰 사건을 촉발.
- **한방 선택:** 성적 투자, 고교/대학·학과, 수시·정시, 직업·정당 선택 등 진행 경로를 크게 변경.
- 과거 선택·현재 능력치·생활 단계에 따라 노출되는 사건·선택지가 바뀜.
- 실패도 계속되는 인생 분기. 대통령이 유일한 목표나 엔딩이 아님.

## 생애 단계 제안
| 시기 | 가능한 게임 시스템 |
|---|---|
| 초등 | 기본 방향성·습관, 반장 출마 |
| 중등 | 학업 투자, 성적에 따른 고교 진학 가능성, 반장 출마 |
| 고등 | **내신/수능** 분리, 생기부 활동, 수시·정시 전략, 반장 출마 |
| 입시·대학 | 수능 결과와 지원 조건, 재수·N수의 비용과 시간, 학과·생활·경력 |
| 사회 | 취업/무직/생활비/건강, 정치 진입 준비 및 입당 시도 |
| 정치 | 정당 선택, 소속당과의 정책 갈등, 지지도와 **당내 신뢰** 구분, 정치적 압박 '보스 사건', 경선·선거 |

## 이벤트 및 UI 아이디어
- 모의고사·내신 노력 선택은 **시험지처럼 꾸민 5지선다 전용 팝업**. 건강·정신적 여유 등을 투자하는 강도를 선택하는 안.
- 내신 위주이면 모의고사에 자원을 덜 쓰는 전략이 가능해야 함. 시험 성적/입학 결과는 현재 능력·투자·조건·확률에 반응.
- 재수 반복은 자금/나이/건강을 소모. N수가 길어지면 백수·다른 진로로 전환하는 사건 후보. 나이별 강제 종결 수치는 아직 미확정.
- 정당 정책과 반복해서 충돌할 때 소속당 신뢰 하락 및 제명 가능성. 대중 지지도 저하와 **당내 신뢰 저하**는 별개다.
- 정치 보스 이벤트: 가상 노동·기업·지역 단체의 집회, 여론 압박, 언론 대응 등. 정치 이념 하나만으로 기계적인 처벌을 부여하지 않는다.

선택 공식, 스탯 범위, 성공확률, 정치 압박 조건 및 단계 구조는 추후 확정. 스탯 [STATS.md](STATS.md), 출생 [REGION_CATALOG.md](REGION_CATALOG.md).

## 2026-10-19 후속 사용자 확정

이벤트는 **소식 이벤트(선택 없음) / 일상 이벤트(일상 선택) / 한방 이벤트(한방 선택)**. **당시** 일상 선택은 기록 아래 버튼, 한방은 공통 대기 연결만 계획했다. **현행** 일상은 별도 모눈종이·보상 시트이고 한방은 시험·고교/대입 원서 UI까지 구현됐다. 이 범위의 구현 계약은 [SYSTEMS.md](../developing/SYSTEMS.md)에 이관했다. 위 생애 단계·확률·속도 제안까지 확정한 것은 아니다.
