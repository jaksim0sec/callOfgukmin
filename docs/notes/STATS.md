# 국민의 부름 — 이전 8스탯 논의안 (보존)

> 상태: **새로운 상태 스탯/특성 논의로 대체됨** (2026-10-19). **최신 기준은 [PLAYER_STATE.md](./PLAYER_STATE.md)**. 아래 8스탯은 과거 제안의 기록으로, 언변·리더십은 현재 **특성**으로 분류하며 생기부 카드 체계는 제외되었다.
>
> 이 문서는 사용자 제공 GPT 발언의 **8개 스탯 구성**을 보존·정리한 것이다. 현재 `game.js`의 스탯이나 과거 `GAME_DESIGN.md` v3의 여섯 능력치·2축 정치 성향을 그대로 가져오지 않는다. 다른 개발 세션에 넘기기 전 초기값, 범위, 전환 시점, 밸런스를 협의해야 한다.

## 1. 제안된 8개 스탯

| 스탯 | 초깃값·활성화 | 변화 및 기능 |
|---|---|---|
| 정신병 수치(표시명 검토: 정신부담) | 0 | 사건·생활·스트레스의 누적 영향을 표현하는 위험 상태 |
| 건강 | 100 | 주로 하락하며 질병·생활·정신적 부담의 영향을 받을 수 있음 |
| 성적 → 경력 | 학생 성적 0, 성인 경력 별도 0 | 학창 시절에는 성적, 성인기에는 경력의 성장 표시 |
| 말빨 | 기본 수치(미정) | 반장·토론·연설·교섭 경험 등으로 증감 |
| 지지도 | 입당 시 0 | 정치 활동 및 선거 활동을 통해 증가 |
| 정치 성향 | 입당 시 활성화 | 좌 ↔ 우 위치형 스펙트럼 |
| 재산 | 플레이어 개인 재산 0원 | 저축·수입·지출 등으로 누적 |
| 용돈 → 수입 | 출생 배경에 따라 결정 | 성장 단계에 따라 용돈·수입으로 변하며, 상황별 보조 정보로 공개 |

- 위 초기값은 **제공된 논의안**의 값이며 게임 밸런스 최종 확정이나 구현 완료를 뜻하지 않는다.
- 특히 **부모의 가구 재산/소득과 플레이어 개인 재산은 구분**해야 한다. 출생 배경을 개인 재산 0원·가정별 용돈에 어떻게 적용할지는 별도 논의한다.
- `성적 → 경력`은 하나의 수치를 이름만 바꾸는 방식이 아니다. 성인기 전환 시 최종 성적은 학력·기록에 보존하고, **경력 수치는 별도 0에서 출발**하는 안이다.
- 정치 입문 후의 지지도 및 정치 성향 표시와 시작 조건은 향후 결정해야 한다. 현재 제안은 **입당 시** 둘 다 활성화하는 방식이다.

## 2. 정신부담과 건강의 관계 — 표현과 규칙

- 제공된 의견에는 '정신병 수치 100 → 암 사망'이 언급되지만, 이를 의학적 사실 또는 직접적 인과관계로 규정하지 않는다.
- 게임에서는 **정신적 부담 상승 → 건강에 간접적 악영향 가능 → 건강이 위험 수준에 이를 때 건강 관련 결말 가능**이라는 분리된 상태 체계가 더 적합하다는 제안이다.
- 실제 정신질환이나 스트레스가 특정 암을 필연적으로 일으키는 것은 아니다.
- '정신병 수치'는 원 발언의 용어이며 UI 명칭으로는 **정신부담** 등을 검토한다. 명칭은 아직 미확정이다.
- 상태 임곗값·상호 영향 공식·회복 가능성·결말 조건은 **미확정**이다.

## 3. 시간 흐름에 따른 상태 전환

| 시기 | 기본 노출 스탯 |
|---|---|
| 유년기·학창 시절 | 정신부담, 건강, 성적, 말빨, 재산 |
| 성인·직장인 | 정신부담, 건강, 경력, 말빨, 재산 |
| 정치 입문 이후 | 위 상태 + 지지도 + 정치 성향 |
| 경제적 선택 및 재산 변화 화면 | 필요 시 용돈·수입 보조 표시 |

- 모든 수치를 메인 화면에 상시 노출하지 않는다. **상황에 의미 있는 스탯을 보여준다.**
- 정치 성향은 입당 전 비표시, 입당 시 등장하는 안이다. 현실적인 사전 성향 형성과의 관계는 추후 협의한다.

## 4. UI 연계

SVG 아이콘, 둥근 토큰, 변화량 색상, 정치 성향 전용 표시 방식은 [UI_TOKENS.md](./UI_TOKENS.md)의 **'차기 스탯 토큰 디자인 논의안'** 절을 참조한다.

## 5. 개발 인계 전 결정할 사항

1. 8개 명칭 중 '정신병 수치'의 최종 표시명 및 각 스탯의 수치 범위.
2. 부담과 건강의 연동, 하락·회복 및 엔딩 규칙.
3. 성적에서 경력으로 전환하는 나이/조건과 학력 기록의 보존 방식.
4. 말빨의 초기값 및 성장 규칙.
5. 지지도·정치 성향을 활성화하는 조건(입당/무소속 정치 활동 등).
6. 부모의 순자산·소득, 플레이어 재산, 용돈/수입의 관계와 출생 분포.
7. 기존 v3 문서·현재 시연 코드와의 충돌을 개발 세션에서 어떻게 이행할지.

출생 지역은 [REGION_CATALOG.md](./REGION_CATALOG.md)의 계층 경로 및 태그로 관리한다. 지역별 경제적 조건/부모 재력 분포는 지역 태그와 직접 결합하지 않고 별도 논의로 확정한다.
