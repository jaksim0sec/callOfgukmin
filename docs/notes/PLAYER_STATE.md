# 인물 상태 체계 — 확정 사항 및 미정 사항

> 2026-10-19 사용자 결정 사항 정리. **미구현 설계 명세**. 아래의 「확정」과 「제안·미정」을 구별하며, 구형 8스탯과 Claude v5 안을 자동 병합하지 않는다.

## 명칭 (확정)

인물 상태는 **속성 스탯**, **상태 스탯**, **특성**으로 구분한다.

| 분류 | 의미 | 예시 |
|---|---|---|
| **속성 스탯** | 현재 배경·신분·소속·자격과 누적 이력. 숫자 증감보다 획득·변경·종료·보존 | 출생지, 집안, 직업, 역할, 학력, 경력 기록 |
| **상태 스탯** | 선택·사건·시간의 흐름에 따라 수치가 바뀌며, 인생 단계별로 생성/교체/종료될 수 있는 지표 | 건강, 재산, 관계, 내신, 인지도 |
| **특성** | 선택이나 사건을 통해 얻는 **토큰형 버프·디버프**. 상태 스탯의 증가·감소, 비용, 조건, 사건 가중치에 작용 | 저축습관, 인내심, 꼼꼼함, 리더십, 언변 |

'고정 스탯/조정 스탯'이나 '인물 속성/변동 지표'는 이 문서 이후 공식 명칭으로 쓰지 않는다.

## 속성 스탯 — 영역 (확정된 분류, 필드 상세 미정)

- **기본정보·출생**: 이름, 나이, 출생 지역. 출생 지역은 [REGION_CATALOG.md](../notes/REGION_CATALOG.md)의 태그 사전을 참조. 과거 사실은 보존.
- **집안**: 부모 직업, 부모 소득/순자산, 가구 지원 여건 등. **개인 재산과 구분**하고 집안 경제상황은 이후 변화할 수 있음.
- **학력**: 다닌 학교·진학/졸업·학위 등. 해당 단계가 종료되어도 기록은 보존.
- **직업**: 현재 직업 및 취업/이직/퇴직 상태.
- **역할**: 반장, 학생회장, 당원, 후보자, 의원 등. 직업과 **동시 보유** 가능.
- **소속**: 학교·회사·정당·단체 등. 현재 소속과 과거 소속 이력을 분리.
- **경력·이력**: 누적 근속, 활동, 재수, 수상, 선거 결과 등. 직업이 바뀌어도 삭제하지 않는다.

속성의 **현재값**과 **과거 기록**은 다르다. 교사→국회의원일 때 직업 속성은 변경되고 교직 이력은 남는다. 직업/역할이 열어주는 행동·지표는 해당 역할 종료 시 비활성화한다.

## 상태 스탯 — 생애 단계 규칙 (사용자 확정)

| 적용 | 상태 스탯 | 발생·종료 규칙 |
|---|---|---|
| **단계 무관, 전 생애** | **정신병, 건강, 재산** | 출생부터 유지하며 증감. 명칭 '정신병'은 기획 필드명으로 기록하고 실제 표시명·의학적 표현은 별도 검토 |
| **학생 시기** | **용돈, 관계** | 용돈은 성인 전환 시 수입으로 변경. 관계는 고교/대학 시기까지 존재하며 종료 시 성과에 따라 관련 **특성**으로 보상/전환 |
| **중학생** | **성적** | 중학교 단계에서만 유지; 고교 진입 시 종료·결과는 학업 이력에 보존 |
| **고등학생** | **내신, 수능** | 중학생의 일반 '성적'을 대체하여 두 지표로 분리. 고교 단계 종료 후 최종 결과는 학력·입시 기록으로 보존 |
| **성인 전환 이후** | **수입, 지지도, 인지도** | 수입은 용돈 대신 활성화. 지지도·인지도는 서로 별개의 수치로 생성; **구체적인 시작값·표시 조건·증감 공식 미정** |
| **직업·역할별** | **미정** | 직업군별로 필요할 때만 별도 상태 스탯을 활성화. 직업 상실·전직 시 종료/보존/전환을 각 기능별 명시 |

- '학생 때'와 '성인 때'의 정확한 전환 기준(만 나이/졸업/역할 기준)은 미정. 대학생처럼 성인과 학생이 겹치는 경우를 처리해야 하므로 **학교 졸업과 법적 성인 여부를 동일시하지 않는다**.
- '관계'를 환산할 때 무조건 언변 하나를 주는 것이 아니다. 관계 수치 및 사건/활동 이력을 기준으로 **언변·친화력·지인 관련 특성** 등의 보상으로 변환하는 안이다. 구체 공식 미정.
- **생기부 전용 카드·스탯 시스템은 도입하지 않는다.** 학교 활동은 필요 시 이력·특성·사건 기록으로 보존한다.
- **리더십·언변(말빨)은 일반 상태 스탯에서 제외**하고 특성으로 처리한다. 상태 스탯에 다시 중복 도입 금지.
- '경력'을 전 직업 공통 상태 수치로 확정하지 않는다. 현재 직업/근속/성과는 속성 또는 필요한 역할별 전용 지표로 분리.
- 이전 1차원 '정치 성향'은 이번 목록에서 상태 스탯으로 명시되지 않았다. **속성/특성/내부 관계 중 어디에 둘지 미정**. 지지도·인지도를 성향과 혼합하지 않는다.

## 특성 — 토큰형 효과 시스템 (명칭/원칙 확정, 수치 미정)

- 특성은 화면에 **작은 토큰**으로 표시되며, 얻거나 잃거나 성장·약화할 수 있다(세부 등급/중첩 규칙 미정).
- **저축습관**: 용돈/수입에서 재산 축적 효율에 긍정 효과를 주는 특성의 예.
- **인내심**: 장기간 도전·시험·업무의 정신적 부담/지속 판정에 도움을 주는 특성의 예.
- **꼼꼼함**: 학습/서류/업무 선택의 결과 판정에 도움을 주는 특성의 예.
- **언변·리더십**: 반장·면접·협상·선거 유세 등 **상황별 판정에 효과**를 주는 특성의 예.
- 긍정·부정 효과 모두 가능하며 무조건 강한 스탯 증가만 부여하지 않는다. 예: 정교한 업무에는 이익이지만 빠른 즉흥 대응에는 비용 증가처럼 **상황 의존형 효과**도 가능(제안).
- 원칙적 처리 순서: `선택 기본 효과 → 적용 가능한 특성의 수정 효과 → 상태 스탯 정산/조건·사건 판정 → 특성 획득·소멸 → 결과 표시`. 중복, 발동 순서, 적용 한도는 후속 확정.
- **속성 스탯**은 '어떤 역할/이력을 가졌는지', **특성**은 '그 이력이 어떻게 행동의 결과를 바꾸는지'를 담당한다.

## 성인 직업·정치 시스템 — 미정 (검토 후보)

확정한 것은 '성인에 수입·지지도·인지도가 생긴다'까지다. **직업별 공통 상태 스탯을 아직 추가하지 않는다.**

- 회사원: 급여(수입), 근속/직급(속성), 필요 시 업무 평판(역할별 전용 지표).
- 자영업·사업가: 매출과 고정비·부채(경제 맥락), 사업 유지 상태(직업별 기능).
- 공무원/교사: 직급·호봉·근무 이력(속성), 직무 이벤트와 공적 책임.
- 정치인/당원: 지지도·인지도(상태), 정당과 소속(속성), 당내 신뢰(정당 관계의 숨은 지표 후보), 정치 성향은 분류 미정.
- 무직/재수/취준: 실업·준비 상태(속성), 생활비·수입 관리, 재도전 사건. 직업이 없다고 시스템이 멈추지 않도록 한다.

## 충돌 및 후속 결정 사항

1. 대학생이면서 성인일 때 '용돈→수입' 전환, '관계'의 종료 시점.
2. 지지도와 인지도는 **성인부터 생성**하되 정치 이전의 지지도 0을 유지할지, 사회 활동의 지지로 사용할지.
3. 성인 직업별 기능을 대표 직업군 단위로 나눌지, 세부 직업마다 만들지.
4. 전 생애 정신병·건강·재산의 기본값/범위, 정신병의 표시명·의학적 오해 없는 효과 구조.
5. 정치 성향을 속성/내부 수치/특성 중 어디에 둘지.
6. 특성 토큰의 등급·중첩·상충·획득 조건 및 장기 영향.
7. 관계를 구체적으로 어떤 특성으로 환산하고, 과거 지인·관계 이력을 별도 보존할지.

**화면 기반만 구현:** 새 UI는 `js/playerState.js`(단계별 상태 목록/속성 보존)와 `js/statusView.js`(학교/특성 SVG 알약, 상태 스탯 렌더)로 이 문서의 표시 체계를 일부 반영했다. **실제 생애 진행, 특성의 버프·디버프 정산, 학교 진학/졸업, 정치 진입은 구현하지 않았다.** 게임 진행을 임의 재활성화하지 않는다.
