# 사용자 원문 개선 목록 — 개별 조정 기록

기준: 사용자 제공8467.jpg 및 직접 입력한 정정. 사진/이전 GPT 추출이 충돌하면 사용자의 직접 정정을 우선한다. 이 문서는 미적용 검토 사항과 확정 사항을 구분하며 미확정 게임 규칙을 뜻하지 않는다.

## 이번 정정 반영

| 선택 | 관계 | 학업 역량 | 압박 | 재산 | 조건 |
|---|---:|---:|---:|---:|---|
| 학교 방과후 | +1 | +1 | +1 | 0 | 없음 |
| 친구들과 놀기 | +2 | −1 | 0 | 0 | 없음 |
| 학원 | +1 | +3 | +3 | −10,000원 | 부모 은수저 이상·재산 충분 |

반장 출마는 압박+2. 당선 시 리더십 **특성**, 반장 **역할**. 리더십+4/열정은 추출 오류이므로 구현하지 않는다. 선거 문맥과 선택 글씨를 강조한다.

## 남은 개별 검토

- 초1은8세, 관심활동은3학년으로 이동. 중·고·대입 연령과 기존 저장/기록까지 일관되게 적용할 방식 검토. 초1 교과서 문구는 실제 교육과정 출처 확인 필요.
- 초등 용돈은 간식비1만원이라는 원문 의도와 적용 범위 검토. 이번 학원1만원 차감과 별개다.
- 대학/사회 경험에서 정치 콘텐츠로 이어지는 과정 설계. 갑작스러운 대통령 전환은 만들지 않는다.
- 칠판 질감·궁서 계열 글꼴·하단 가림 개선.
- PWA manifest/로컬 오프라인 지원. 파비콘은 별도 논의.
- 포스터 문구의 무게·길이·얼굴 가림, 나이/직업/학년/이름 배치와 작은 중복 라벨 제거 검토. Canvas 해상도와 CSS em 단위를 구분한다.
- 공유 이미지의 특성·졸업고교/대학·성적·수시/정시·재산·실제 N수 여부를 개별 조정. 현재 저장된 게임 점수를 공식 수능 원점수처럼 꾸며 표시하지 않는다.
