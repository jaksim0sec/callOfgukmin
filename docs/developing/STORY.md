범위: 출생~고3 수능 이전. 성인·정치·대학·수능 응시 후 콘텐츠는 변경하지 않는다. `main`에서 분기한 기능 브랜치에 기록했다.

각 단계의 필수 진행 소식 ID와 각종 시험 선택 ID는 여전히 전부 정의되어 있다. 과거 대기 선택의 `scenarioId`가 없다면 기존 단일 선택지로 처리한다. 기본 대체 후보는 우선순위 0이며 **각 슬롯에서 반드시 하나의 사건만 발생**한다. NPC 이름은 새로고침마다 섞지 않는다.

### 시험·소식 계층의 호환 처리

`middle`의 학년별 기존 시험 6회, `high`의 학년별 연간 모의·내신 선택 6회, 구 고교 시험 ID 12개(새 진행에서는 비활성화) 모두 정의 유지. 반복되는 `exam-classroom:*` 소식은 새 UI 기록에서 숨겨 시험 예고 하나만 보이게 한다. 기존 기록은 삭제하지 않는다. 기존 성적 `schoolScore`, 수능 관련 모의 지표 `exam`의 내부 ID는 유지. 수능 실제 응시는 구현하지 않는다.

## 시나리오 판정·저장 동작

1. `GukminDirector.content(persona)`는 변형 후보를 **정의만** 하고 조건을 미리 선택하지 않는다.
2. `GukminTimeline.pump`는 사건을 시작할 때 그 시점의 인물 상태, 과거 `attributes`와 기존 특성으로 후보를 내림차순 검토한다.
3. 가장 먼저 매칭된 변형의 ID는 `runtime.choices[token].scenarioId`에 저장된다. 기본 `choiceId`와 사건 ID는 변경하지 않는다.
4. 저장 후에는 특성·관계가 바뀌어도 그 선택의 시나리오를 재선정하지 않는다. 해소할 때도 저장된 변형의 옵션으로 정산한다.
5. 기존 열린 대기 세이브에는 `scenarioId`가 없을 수 있다. 이 경우 원래 정의의 옵션과 결과로 진행한다.

## 상태 수치와 서사 일치 검수

- 대화·짧은 짜증·사진 촬영으로 건강이나 스트레스 지표를 고치지 않는다.
- 관계 증가가 있는 경우에는 실제 대화·약속·협력 결과가 **이야기 속에 발생**해야 한다.
- 학업 지표가 오를 때에는 질문 자체가 아니라 실제 연습·복습·분석을 결과에 명시한다.
- 장기 특성은 적성처럼 탐색 후 반복 경험이 있을 때 지급하며, 작은 행동은 숨은 속성으로 기록한다.
- `money`만 소비 비용을 표현한다. `allowance`는 턴별 지급량이다.
- 수능 이전 전략에 점수 증감은 없고 행동과 일정만 남는다.
- 선택 효과가 없어도 결과 문장은 사건에 맞게 따로 작성한다. 클라이언트는 없는 보상 토큰을 만들지 않는다.

## UI와 테스트 유의 사항

- `GukminMarkup.render`는 텍스트 노드로 HTML 원문을 이스케이프하고 네 가지 한정 마크업만 DOM 요소로 렌더한다. 인생기록·설명·옵션·결과를 연결한다.
- 리뷰 상태는 `simulation.awaitingContinuation` 하나를 사용한다. 실제 선택 직전의 값은 `reviewBefore` 선택적 스냅샷에 남겨 새로고침 시에도 변화칩을 계산한다.
- 사용자 입력으로 `resume()`되기 전에는 다음 이야기로 이동하지 않는다. 팝업 접기는 선택을 적용하지 않는다.
- 브라우저 자동 검증은 Chromium 데스크톱 1365×900, 모바일 390×844·360×640이다. 실기기 Safari/삼성 인터넷과 저사양 성능, 완주 평균 플레이 시간은 자동화에서 별도 입증되지 않는다.
- 테스트 실행 명령: `node tests/smoke.mjs`, `node --test tests/systems.mjs`, `node tests/browser.mjs`. CI는 위 세 명령을 실행한다.

## 이번 범위에서 의도적으로 추가하지 않은 것

새 상태 스탯, 새로운 턴·리뷰 상태, 외부 라이브러리, 성인·정치 콘텐츠, 수능 응시 결과, NPC 대규모 관계 테이블, 이벤트 ID 마이그레이션, 바텀시트 재설계, 저장 키 변경 없음.

## 같은 턴의 연속 선택 (선정 시점 보장)

한 턴에 시간 진행을 차단하는 선택이 두 개 이상 존재해도 먼저 등록된 하나만 대기 선택으로 연다. 첫 선택의 정산과 리뷰가 끝나 `resume()`를 호출한 시점에야 다음 선택을 연다. 따라서 뒤 사건은 앞선 결과로 갱신된 인물 상태를 보고 분기된다. `blocksTime:false` 비차단 선택은 기존처럼 같은 턴의 뒤 이벤트를 늦추지 않는다.

누군가가 옛 버전에서 같은 턴의 다중 선택을 이미 저장했다면 `awaitingContinuation` 중에는 다음 선택을 UI에 노출하지 않고 리뷰를 먼저 마친다. 새로운 리뷰 상태를 만들지 않는다.

## 선택 응답과 사실 기반 리스크 (2026-10-20)

- 일상 선택 후 `dialog`를 즉시 닫고 새 결과를 인생 기록에 대화형 소식으로 보여 준다. 기존 `awaitingContinuation` 상태는 유지하며, 기록의 다음 이야기 버튼만 재개를 실행한다.
- 각 닫힌 선택은 기존 `runtime.choices[token]`에 선택 문구와 해당 선택이 만든 기록 구간, 정산 직전/직후의 관찰값 `outcome`을 선택적으로 보존한다. 과거 세이브에 필드가 없어도 정상 진행한다.
- 선택지의 선택적 `risk`는 미리 알 수 있는 부담·충돌을 설명한다. 수치 효과는 실제 사건이 묘사하는 학습·관계·시간 부담에 따라 작성하고, 불확실한 사건을 자동 성공으로 표시하지 않는다.
- `elementary:project`의 지역 사진 정정은 직접 조사(학업+1, 스트레스+2), 조원과 수정(관계+2, 스트레스+1), 논란 사진 삭제(관계−1, 스트레스+1)로 대가를 구분한다. `high:teamwork` 세아의 실험 오류도 늦은 재작업·정정 제출·자료 제외의 부담을 다르게 처리한다.

## 2026-10-20 인과/학업/경제 전면 재점검

- 평가 결과는 마지막 클릭 하나로 정해지지 않는다. 실제 출발점은 이전 학업 역량이다. 고등학교 첫 모의고사 기초값은 중학 동안 쌓은 `study`와 지원 가능한 학교 유형에 따라 보정된다. 과학고는 내신과 누적 학업 역량을 함께 만족해야 지원 가능하고, 그 학업 이력을 수능형 모의고사 45점으로 초기화하지 않는다.
- 다섯 시험 전략은 모두 장점이 있다: 휴식·컨디션, 핵심 복습, 꾸준한 학습, 오답 정리, 고강도 대비. 마지막 선택지는 부담이 더 크며 자동 최적해가 아니다. 성적은 기존 `exam/schoolScore`에 누적 공부 기반 보정, `꼼꼼함` 특성 보너스를 정산한다.
- 개인 재산 `money`는 부모의 교육 예산이 아니다. 학원·유료 진학 상담은 현실에 맞춘 월/회차 비용(학원 16~23만원, 상담 12만원 등)을 보여주되, 가구 지원이 있다면 학생 개인 재산에서 차감하지 않는다. 직접 비용을 낼 때만 충분한 개인 재산이 있어야 한다. 무료 학교 교실·친구 스터디도 학습 효과를 갖는다.
- 과학고 지원 시 교통·숙식 비용은 월 비용의 **시연 추정치**이며 지원료도 학비도 아니다. 진학 조건에는 학생 개인 현금 잔액을 사용하지 않는다. 고교 무상교육의 적용 범위와 예외는 학교 유형에 따라 다를 수 있으므로 학교마다 확인한다.
- 과학고·영재학교의 아침 사건은 일반고의 통학 지각 사건 대신 실험실 준비 사건이 나온다. 선택과목 폐강도 과고·영재학교에서는 공동 실험실 예약 문제로 별도 분기한다. 이는 통학·기숙사 여부를 함부로 단정하지 않기 위함이다.
- 새 사건: 유년기 블록 탑, 초등 급식 닭강정, 중학 단톡방 과제. 관계 변화는 상대 반응과 실제 협력에 따라 주고, 변화 없는 선택은 결과·기록에 의미를 부여한다.
- 특성은 초등 반장 활동을 마무리한 뒤 리더십, 중학 한 달 오답·방송부 루틴을 끝낸 뒤 꼼꼼함/인내심 등 실제 경과가 있는 곳에서 지급한다. 효과는 태그 조건의 실제 학업 정산에 연결한다.
