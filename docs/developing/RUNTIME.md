| 파일 | 역할 |

| `tests/smoke.mjs` | 정적 파일·DOM·문법·실제 진행 코드 미포함 검사 |

## 반응형 화면 계약

- **PC 761px 이상**: 전체 화면 안에 2열 × 2단. 왼쪽 포스터 위/나이·학력 상태표 아래, 오른쪽 능력치 프로그래스 위/인생 기록 아래. PC 히스토리는 고정 바텀시트가 아니며 기록 내부 스크롤만 허용.
- **모바일 760px 이하**: 포스터+상태표 가로 배치, 그 아래 능력치, 화면 아래 고정·항상 열려 있는 인생 기록 바텀시트. 더 좁은 화면은 능력치 2열.
- 포스터는 독립 이미지 레이어를 가지며 아직 캐릭터 그림 대신 익명 실루엣을 사용. 이름·기호·문구·정당색은 공통 DOM API로 처리.

## 현재 모델

- 랜덤 가정/지역/이름을 골라 0살 새 인물을 생성하고 출생 이력 2개를 표시한다.
- UI 검증용 상태: 정신부담 0, 건강 100, 성적 0, 개인 재산 0. 말빨은 미정, 정치 지지도·성향은 미활성. 확정 게임 밸런스가 아니다.
- 새 세이브 키 `callOfgukmin__ui__v1` 사용. 과거 플레이 저장 키 `callOfgukmin__playable__v1`을 덮어쓰거나 삭제하지 않는다.
- 진학 서류·정당 투표지는 **UI 미리보기**. 선택 후 인물 정보·나이·스탯·기록은 변하지 않는다.
- 사건 루프, 시간 진행, 선택 스탯 변화, 경선·선거·엔딩은 활성화되어 있지 않다.

## 검증 및 한계

- `node tests/smoke.mjs` 실행.
- 로컬 Chromium의 인라인 렌더에서 PC 1366×768, PC 1120×700, 모바일 390×844 및 735×1320의 영역 위치·가로 넘침을 확인.
- 모바일 학교 선택 UI를 열어 옵션·확정 동작 뒤 나이가 0세인 것을 확인. 실제 GitHub Pages 반영/배포는 별도 확인 필요.
- `docs/notes/`에 있는 스탯과 생애 단계·선거 수치는 여전히 미확정이며, 검토 없이 런타임으로 이식하지 않는다.


## CSS 스케일링 계약 (2026-10-19)

- **상세 규칙**: [CSS.md](CSS.md). CSS 수정 전에 읽고 같은 작업에서 규칙을 검토·갱신한다.
- 모바일 기본 16px, PC `:root` 15px. 그 외 고정 단위는 `rem`/`em`, 미디어 쿼리 분기는 `em`.
- PC 왼쪽은 flex, 포스터/학력 패널 너비 완전 일치. 모바일 UI 배치·바텀시트는 유지.
