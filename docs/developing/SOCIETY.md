# 사회 — 성인기 연결 계약

현재 학생기 선택과 입시 결과를 바꾸지 않고 대학/사회 진출이 확정된 다음 소식 이벤트에서 사회 허브로 연결한다. 고교 중퇴/검정고시 콘텐츠를 새로 만들지 않는다. 기존 고졸·대입 재도전 사회 진출과 합격 진학 경로가 대상이다.

사회는 기존 생애 오퍼레이터 하나다. 반복 한방 선택의 스크립트는 열리는 순간 인물에 맞춰 동결하며 비용/기간/결과를 공통 정산한다. 별도 세계 엔진이나 매 턴 급여는 없다. societyMonths의 경과 개월과 기준 나이로 학업/복무/경력 시간을 기록하며 학생기 턴에 달력을 소급하지 않는다.

대학은 학제와 연간 활동만 다룬다. 학비 분담은 집안 등급별 시연값이며 장학·아르바이트·대출·휴학과 현금의 교환을 제공한다. 현행 실무계열 표본은2/3년제 과정을 선택하고 일반 학사 과정은4년이다. 3년제 실무과정 졸업은 추가 기간/학비 대신 현장 실무직 초임에 월30만 원의 시연 우대를 주어 무료 단기훈련과 구분한다. 실제 학교의 학과별 기간/등록금 공시를 대신하지 않는다.

병역은 대한민국의 육군18/해군20/공군21개월을 참고한다. 보충역 실제 판정은 재현하지 않고 현재 남성의 판정 시 정신병2 이상은 사용자가 지정한 게임 규칙상 복무 제외로 기록한다. 법적 병역 등급/의학 진단을 부여하지 않는다. 여성은 병 모집 대신 부사관 자원 경로(의무복무4년)를 사용하며 남성도 같은48개월 경로를 고를 수 있다. 여성의 자원복무 보너스는 관계1뿐이다. 복무 중 학업은 휴학하며 전역 후 직접 복학한다. 병역 상태·기간·사유는 정치 입문 후에도 유지한다.

취업은 기업/공공/지역 실무 지원, 직업훈련, 자기자본 자영업을 제공한다. 학력/학생기 특성/이전 활동/관계/경력 공백에 따라 결과가 달라진다. 고정 시드와 지원 회차로 새로고침 재추첨을 막는다. 돈은 실제 일한 기간에 생활비를 정산하고 프로젝트/협업/생활 조정의 다른 비용으로 바뀐다.

정치 입문 준비는 대학/졸업/취업을 강제하지 않는다. 현역 복무와 공공기관의 정치적 중립 신분에서는 진입을 막고 신분 정리를 요구한다. 정당 가입 가능 연령16세, 후보 피선거권18세는 만 나이 기준이며 생일을 저장하지 않는 게임에서는 세는나이−2의 보수적 하한으로 확인한다. 시민 활동을 선거 출마로 취급하지 않는다. 이번 범위는 입문 경로/이력의 확정까지이며 정당 조직/실제 선거는 다음 개발이다.

## 구현·저장과 검증

societyStep은 hub/college-program/college-funding/college-year/military/military-service/career-search/job-offer/work/business/politics/ready다. 각 단계는 일반 한방 이벤트/선택이며 별도 이벤트 계층을 만들지 않는다. zero-month 진로 검토와 실제12개월 학업/군별 복무/2~6개월 취업 활동을 구분한다. 국공립/사립 학비 전체를 재현하지 않고 연간 등록금 시연값과 가족 지원0/25/50/100/100%를 제공한다. 학자금은 원금만 기록하며 휴학 중 이수 기간을 자동으로 늘리지 않는다.

근무·직업군별 경력 개월, 과거 분야 비트마스크, 업무 실적과 전환 사유는 scalar 속성/attributeHistory/인생 기록으로 보존한다. 누적 실무 경험은 재지원에 작은 보너스를 주며, 공직은 경력 보너스 상한이 더 낮다. 회사에 재직한다는 이유로 매 턴 수입이 발생하지 않는다. 복학은 직장을 중단하는 전환이고, 대학 아르바이트만 연간 학업과 병행한다.

정치 입문은 실제 입당·출마가 아니라 party/local/independent 준비 경로를 기록한 경계다. 지방행정직 공무원은 퇴사 전 정치 입문이 차단된다. 일반 공공기관 전체를 금지 신분으로 취급하지 않는다. 병역 미이행/제외/복무 완료와 정신건강 사유를 구분하며, 미래 미필 꼬리표를 위해 militaryServed와 입문 시점의 복무 여부도 남긴다.
