# 현재 구현 — 포스터·화면 구성

> 2026-10-19 기록. **CSS를 수정하기 전에 [CSS.md](CSS.md)를 먼저 읽고 함께 갱신한다.** 실제 코드가 바뀌면 `html/game.html`, `js/statusView.js`, `js/poster.js`, `css/style.css`를 확인한다. 스탯 SVG 토큰은 아직 [미확정 UI 초안](../notes/UI_TOKENS.md)이다.

## 공통 DOM 포스터 함수 (2026-10-19 반영)

- 신규 `js/poster.js`가 `window.GukminPoster.create(data)`로 **HTMLElement를 반환**한다. 기존 요소는 `window.GukminPoster.update(element,data)`로 재사용·갱신한다.
- 게임 `renderStatus()`는 직접 포스터의 각 DOM을 수정하지 않고 `#playerPosterMount`의 포스터 생성/갱신 함수만 사용한다.
- 필드: `color`(HEX 정당색), `partyName`, `partyIcon`, `phrase`(상황별 상태 문구), `stage`(현재 단계/직업), `name`, `number`(후보 기호, 없으면 숨김), `imageSrc`(이미지 경로), `ageGroup`, `template`.
- 배치: 상단 정당 로고·정당명/단계 → 중앙 이미지 → 하단 상태 문구 → 맨 아래 `기호 N번`과 큰 이름. 기호는 실제 후보가 된 단계에서만 표시.
- 인물 이미지는 독립 `<img>` 슬롯에 `object-fit: contain; object-position: center bottom` 적용. `imageSrc`가 없거나 불러올 수 없으면 기존 익명 인물 컨셉의 SVG 실루엣으로 대체. 향후 8인 캐릭터/성장 연령별 자산 경로를 데이터에서 연결할 수 있다.
- 색상은 `--poster-party`에서 적용하고 `solid`(기본 정당색 전면), `light`, `minimal` 구도 지원. 현재 게임은 `solid`를 사용한다.
- 렌더러에서 사용자 문자열은 `textContent`로 쓰고 색상은 HEX만 허용한다.


## 현재 화면 계약 (2026-10-19)

- **CSS 단위·PC/모바일 규칙의 기준 문서는 [CSS.md](CSS.md)**. CSS 변경에 앞서 반드시 읽고 관련 수정 시 함께 갱신한다.
- **PC (약 761px 이상)**: 왼쪽은 **포스터와 상태표가 같은 너비인 수직 flex**, 오른쪽은 능력치(상) + 인생 기록(하). PC의 기록 패널은 고정 바텀시트가 아니다.
- **모바일 (약 760px 이하)**: 기존 포스터/학력 가로 2열 + 능력치 + 고정 히스토리 바텀시트를 그대로 유지한다.
- 루트 폰트 크기는 모바일 16px / PC 15px, 자식 크기와 간격은 rem/em을 기준으로 한다. 포스터 텍스트도 포스터 상위 글꼴 크기를 기준으로 em 배율을 사용한다.
- 현재 UI는 인물 생성·저장과 공통 세션 상태·선택을 표시한다. 실제 생애 콘텐츠는 없고 검증용 진행을 별도로 제공한다. 화면 DOM은 루트 `index.html`이 아닌 `html/game.html`에서 불러온다. 이전 `renderStatus()` 등은 구 시연 이력이며 현행 구현은 `js/game.js`의 `render()`가 `GukminPoster.create/update`를 호출한다.

## 화면 분리 및 현재 상태 토큰 (2026-10-19)

- `index.html`은 `html/waiting.html`으로 이동시키는 루트 진입점. `html/waiting.html`은 대기(출생·포스터/시작·재추첨), `html/game.html`은 인게임, `html/result.html`은 **엔딩 미구현 미리보기**.
- `js/boot.js`가 페이지 이동과 각 화면 초기화를 담당하며, `js/game.js`는 인게임에만 실행된다. 화면 로드는 `fetch()`가 아닌 정적 HTML 문서 단위다. 자세한 소유권: [RUNTIME.md](RUNTIME.md).
- 왼쪽 프로필 하단에는 **속성 스탯(집안·출생·역할)** + **학교 이력**만 표시. 학교는 사용자가 확정한 **배경색 알약 + 내부 흰색 stroke SVG + 학교명**. `enrolled` 상태만 기존 알약 구성 그대로 배경/테두리 강조, `graduated`는 차분한 톤.
- 오른쪽 `.gauges`는 단일 하드코딩 게이지 나열을 제거하고 `#gaugesList`에서 활성 상태 스탯을 동적으로 렌더한다. 기본 정신병·건강·재산, 성장 단계별 용돈/관계/성적/내신/수능/수입/지지도/인지도는 정의만 있고 아직 진행하지 않는다.
- **특성은 상태 스탯 프로그래스 바로 아래** `.trait-section > #traits`. 작고 둥근 알약에 **하얀 선 SVG 아이콘 + 이름**을 사용. 저축습관/인내심/꼼꼼함/리더십/언변 등의 표시 정의를 유지하며 콘텐츠에서 획득·제거·상황 수정·반복 효과를 정의한다. 실제 기본 밸런스는 미정.
- 아기 출생 데이터의 '집안'을 특성으로 넣지 않는다. 가족 배경은 속성, 특성 토큰은 실제 버프/디버프만 나타낸다.

## 공통 기반 연동 (2026-10-19)

공통 효과·턴·이벤트·선택 기반을 추가했다. [SYSTEMS.md](SYSTEMS.md)가 데이터 계약이다. 기존 포스터·상태·특성·학교·기록 렌더러가 확정된 세션 상태를 표시한다. 기본 인생 기록 아래의 상태/미리보기 블록은 일상 선택 영역으로 교체했고 타이틀 아래에 실제 다음 선택 진행도를 배치했다. 한방 선택은 대기 및 후속 UI 연결만 제공한다. 학교·정당 미리보기는 검증 모드에서 유지하며 데이터를 바꾸지 않는다.

## 출생 인트로 (2026-10-19)

- 대기 화면의 기존 포스터·메뉴 구성은 변경하지 않고 `#birthIntro`를 최상위 화면 오버레이로 사용한다. 카드의 간결한 인쇄물 레이아웃, 기존 보라색 계열과 굵은 제목체를 재사용한다.
- 인트로에는 저장된 이름·출생지·집안만 표기한다. PC와 모바일 모두 화면 안에서 완결되며 건너뛰기·키보드 Escape·동작 줄이기 설정을 지원한다.
- 인트로 UI에 새 인생 판정, 애니메이션 기반 실제 게임 턴, 카운트다운 상태값을 끼워 넣지 않는다. `CSS.md`의 단위·반응형 규칙을 동일하게 적용한다.

## 수저 출생 토큰 (2026-10-19)

- 인게임 특성 알약과 인트로의 수저 토큰은 `GukminStatus.traitToken(name)`을 공유한다. 새 SVG 컴포넌트를 만들지 않는다.
- 재력별 컬러는 `trait-tier-soil`부터 `trait-tier-diamond`까지 의미 기반이며 인트로의 기존 카드 레이아웃/전환은 보존한다.

## 고교 입시 및 내신 UI (2026-10-19)

- `#lifeDecisionDialog`: 게임 정면의 밝은 종이 시험지. 중학교 중간·기말, 고등학교 중간·기말, 3월·6월 모의고사를 **다섯 개 노력을 나타내는 선택지**로 보여 주며 통계 증감 배지를 표시한다.
- 고교 지원서는 같은 별도 창에서 학교명·학교 종류·게임 내 지원 제한·효과를 보여 준다. 실제 교표 이미지를 확보한 경우에만 사용하고 나머지는 **임시 문자형 학교 마크**를 사용한다.
- 모든 주요 선택은 `GukminGame.registerMajorPresenter`과 기존 정산 토큰을 재사용한다. 창을 닫아도 선택은 대기 상태로 남으며 다시 열 수 있다. PC 2열 메인 / 모바일 고정 바텀시트는 변경하지 않았다.

## 학교 지원서 자료 확인과 반응형 검증

- `majorView.js`의 학교별 부제는 학교 유형을 분리하여 표시하며 게임 내 내신/학업 지원 기준을 숫자로 명확히 적는다. 해당 수치는 공식 합격선이 아니다.
- 각 후보를 선택하면 서류 하단 자료 링크가 해당 학교 확인 페이지로 갱신된다. 출처가 확인되지 않은 학교는 고입정보포털로 연결한다. 임시 글자 마크는 실제 교표로 표시하지 않는다.
- CI에서 Playwright Chromium을 설치하고 1365×900 / 390×844 / 360×640의 기존 화면과 실제 0~19세 생애 흐름·시험/지원서 모달을 자동 검사한다. 화면/저장 복구 테스트는 `tests/browser.mjs`.


## 시험지·일상선택 상세화 (2026-10-19)

- 일상 선택은 전폭 세로 카드로 번호·이야기·효과를 정리한다. 1열을 벗어나 나란히 나열하지 않는다.
- 상태 스탯에는 각 아이콘과 의미색 게이지를 사용한다. 내신은 파랑, 모의고사는 주황. 두 성적의 표시는 게임 예상 5등급/9등급이며 실제 석차가 아니라고 안내한다.
- 시험지에는 교시/평가 영역/성명·학년·번호/문제 번호와 5지선다를 넣었다. 실제 문제를 푸는 화면이 아니라 노력 수준을 결정하는 게임 서류다.


## 2026-10-19 선택 가독성과 결과 확인

- 출생 오버레이 제목은 `출생신고서`. 이름·출생지·가정·수저 토큰과 `10초 후 출생` 프로그레스, `출생하기` 버튼을 제공한다. 사용자 선택에 따라 즉시 시작할 수 있다.
- 일반 일상 선택은 기록 위에 한 줄에 하나씩 표시된다. 선택 결과마다 공통 metric SVG 색 토큰을 사용한다.
- `GukminGame`은 선택 정산 직후 신규 선택을 바로 렌더링하지 않는다. 새 인터스티셜 화면에 저장된 실제 **선택 결과**와 `다음 이야기 보기` 버튼을 표시하며, 사용자가 버튼을 눌러야 다음 사건으로 진행한다. 기록은 최신 사건이 맨 위에 온다.
- 모바일 기록 시트는 클릭하여 펼치고 줄일 수 있지만 닫히지 않는다. 시트 내 선택·히스토리를 하나의 스크롤로 연결해 잘리는 문제를 줄였다. 시트 헤더의 큰 글씨는 현재 나이, 보조 제목은 현재 초·중·고 학년이나 생애 단계다.
- 속성과 상태 패널의 위치를 교체. 선택 진행바가 `선택 대기`일 때는 완료된 듯 100% 차게 두지 않는다.

## 바텀시트·상태 스탯 긴급 수정 (2026-10-19)

- 모바일 손잡이는 초기 45/75dvh에서 20dvh 내외로 축소하고 다시 90dvh까지 펼친다. 축소해도 시트 헤더와 진행도는 유지된다.
- 정신병/건강만 한 줄 2열이며 다른 스탯은 각각 한 행이다. `stress`는 저장 호환용 내부 ID이고 UI 명칭은 `정신병`이다.

## 바텀시트 중간 단계 (2026-10-20)

- 모바일 인생 기록 시트는 축소·중간(55dvh)·전체 세 단계. 중간에도 선택과 기록을 볼 수 있고 단일 스크롤 유지. 손잡이 탭 순환과 위·아래 드래그 스냅.

## 일상 선택 가독성 및 결과 흐름 (2026-10-20)

- 현재 상황 제목/본문을 강조한 패널, 행동은 별도 목록, 스탯 변화 토큰은 보조 정보. 선택 후 결과는 결과 확인 화면에 표시.
- '다음으로' 버튼은 실제 다음 등록 이벤트로 진행하며, 결과 확인 중 가짜 시간 게이지를 숨긴다.

## 학생 스탯·특성 (2026-10-20)

- 특성은 상태 스탯 위의 공용 flex 토큰. 공통 학사모 SVG와 4종 적성 색상. 학업 역량은 내부 보존, 중·고 화면에서는 숨김. 성적 게이지 하단의 반복 안내 문구 제거.

## 학교 지원 요건 일치 (2026-10-20)

- 지원서에 현재 게임 내신 원점수와 필요 원점수를 함께 보여준다. 잠금 판정도 동일한 원점수를 사용하며, 표시하지 않는 학업 역량을 조건에 추가하지 않는다.
