## 1. 기준 글꼴 크기와 단위

- **모바일/기본**: `:root { font-size: 16px; }` (기존 모바일 시각 크기 유지).
- **PC 761px 이상**: `@media (min-width: 47.5625em) { :root { font-size: 15px; } }` (PC UI를 소폭 축소).
- **루트가 아닌 선택자의 길이·크기·간격·테두리·그림자 오프셋은 `rem` 또는 `em`으로 작성**한다. 기본 `1rem`은 현재 문서 루트 글꼴 크기를 따른다.
- 일반적인 크기·간격은 `rem`, 글꼴/컴포넌트 내부 비례 크기는 `em`을 기본으로 한다. 포스터 내부의 글꼴 크기도 `em`을 사용한다.
- 상위 컴포넌트 비율·유연한 레이아웃을 위해 `%`, `fr`, `auto`, `vw`, `dvh`, `calc()`, `clamp()` 등은 필요한 경우 유지할 수 있다. 고정 `px`은 **루트 글꼴 크기 정의에만** 허용한다.
- 반응형 분기 `@media`는 **`em` 단위**로 작성한다. 미디어 쿼리의 `em`은 문서에서 변경한 `:root` 값이 아니라 브라우저 초기 폰트 크기(통상 16px)를 기준으로 평가되므로, 루트 크기를 바꿔도 기기 분기는 안정적이다.
- 예: `padding: 1rem`, `gap: .75rem`, `border: .0625rem solid`; 잘못된 예: `padding: 16px`, `width: 280px`.

- 상태 스탯 고유색은 파스텔 대신 채도와 명도를 조정한 색상: 스트레스 `#D65B62`, 건강 `#32A878`, 재산·용돈·수입 `#D7A13C`, 관계 `#8769D8`, 학업 `#6F82BA`, 내신 `#3F7FD5`, 모의고사 `#C77A29`, 지지도 `#258F9B`, 인지도 `#AE6A9D`. 게이지 원색 대비 숫자/아이콘은 흰색을 혼합해 읽기성을 확보한다.
- `#dailyChoiceDialog`는 독립적인 중앙 카드형 네이티브 `dialog`로, 배경 블러와 내부 스크롤을 제공한다. 바텀시트의 20/55/90dvh 스냅·관성·드래그·DOM 구조와 독립적이다.
- 선택 팝업의 접기·Escape·배경 누름은 응답을 정산하지 않고 창만 닫는다. `#resumeDailyChoice`는 `.sheet-head` 안에 있어 시트가 최소화되어도 `선택 진행 중 · 열기`가 보인다. 시트 본문에는 간결한 선택 요약과 다시 열기 버튼만 제공한다.
- 선택 확정 시 게임의 실제 정산값에서 수치 변화·특성 획득/상실·학교/역할 변화를 추출하여 동일 팝업의 결과 토큰으로 출력한다. 고유 스탯 색과 긍정/부정 강조를 분리한다. 최소 높이 모바일의 팝업은 뷰포트 안에서 내부 스크롤하며 `prefers-reduced-motion`을 따른다.
- CSS 변경은 기존 확정 `rem/em` 스케일을 유지하고, 기존 시험지·학교 지원서 모달이나 한방 선택 프레젠터는 변경하지 않는다.

## 25. 생애 스토리 제한 마크업·팝업 흐름 (2026-10-20)

- `js/dailyChoice.js`의 `GukminMarkup.render`가 문자열을 텍스트 노드와 안전한 `strong/em/del/mark` DOM으로 변환한다. `**굵게**`, `*기울임*`, `~~취소~~`, `==형광펜==`만 인정하며 HTML을 삽입하지 않는다. 사건 설명·선택지·결과·인생 기록에 공유한다.
- `.daily-choice-dialog::backdrop`는 기존 큰 `blur(.55rem)`에서 미약한 `blur(.12rem)`과 불투명 톤으로 단순화한다. `prefers-reduced-transparency`에서는 블러를 생략한다.
- 강조 텍스트는 한 문장 핵심에만 배경색을 적용하며 `.record p`, `.daily-choice-story`, `.daily-result-lead`, `.review-detail`에 줄바꿈을 보존한다. 모든 크기는 rem/em 단위다.
- 선택 팝업의 스크롤은 `.daily-modal-body`만 처리하고 기존 영구 바텀시트의 스냅 높이와 제스처는 수정하지 않는다. 리뷰 상태 재접속 시 팝업 내용은 저장된 결과로 복원하되 새 UI 저장 키나 진행 상태는 만들지 않는다.

## 26. 선택 후 기록형 답장과 손익 표시 (2026-10-20)

- **현행** 일상 선택 확정 시 같은 `dialog`에서 보상을 표시한다. `보상 받기` 또는 닫힘 완료 뒤에 기록·다음 사건으로 전환하며, 인생 기록 시트의 3단계 스냅은 유지한다.
- 기록은 오른쪽 `.record-player-message` 선택 문구와 아래 `.record-result-message` 결과 소식으로 구분한다. 실제 적용된 스탯/특성 변동 토큰 `.record-impacts`는 결과 아래에만 붙고 최신 정산에만 짧게 등장한다.
- 팝업 옵션의 `.daily-choice-risk`는 콘텐츠가 명시한 시간·관계·비용 등 부담만 보조 문구로 보여 준다. 모든 행동에 임의의 음수 보상을 강제하지 않는다.
- 선택 리뷰의 `다음 이야기 보기`는 기록에 있으며 리뷰 대기 중 자동 진행하지 않는다. 기록 렌더는 스냅 높이·세이브와 무관하다.
- 작은 모바일 화면에서는 기록 말풍선의 최대 너비·글꼴을 줄이고, 모든 새 크기 단위는 rem/em이다. reduced-motion 사용자는 칩 애니메이션이 없다.

## 2026-10-20 일상선택 리듬과 특성 색
- 일상 모달: 제목은 헤더에서 한 번만 보여 주고, 본문은 이야기/결정/대가 순으로 읽힌다. 본문의 Markdown 줄바꿈은 안전한 DOM `br`로 출력한다. 글꼴 크기·굵기 위계와 선택 버튼의 터치 범위를 유지하면서 군더더기를 줄인다.
- `.daily-choice-dialog[open]`과 backdrop은 아래쪽에서 가볍게 올라오며 0.3초 안팎에 끝난다. `prefers-reduced-motion`에서는 효과가 사라진다.
- `.choice-progress-track`의 내부 `#choiceProgressFill`은 **실제 논리 턴 진행률**을 transform으로 보간한다. 기존 `progress#nextChoiceProgress`는 접근성과 테스트용 실제 값이며 시각 채색만 커스텀 바가 담당한다. 선택/정산 중 바는 사라지지 않고 정지 상태를 나타내며 시간을 새로 추정하거나 카운트다운을 조작하지 않는다.
- 중간 소식은 `#lifeNewsToast`를 약 1초 노출한 뒤 기록에 보존하고, 다음 턴 진행을 재개한다. 비차단 소식은 기존 시트 DOM을 재생성하지 않는다. 새 기록만 `.record-arrived` 진입 연출을 준다.
- `.token-trait[style*="--trait-color"]`은 특성별 색을 변수로 받아 밝은 SVG와 유색 배경·테두리를 만든다. `negative` 특성은 붉은 계열을 쓰며 상승 보상으로 오해하게 꾸미지 않는다. 숨은 관심은 옅은 `관심 · 예체능` 토큰으로 보여 주고 정식 특성 승급 시 대체한다.
- 요소 간격·높이·테두리·그림자는 rem/em 기준. 390×844과 360×640의 모바일용 `max-height`와 스크롤 경계를 건드리지 않는다. reduced-motion에서 시간 지연과 애니메이션은 최소화한다.

## 2026-10-21 모바일 기록 시트 경계 정렬

- 이전의 20/55% 비율 고정 스냅은 상태·학교 토큰이 길어질 때 프로필과 충돌했다. 카드 각각에 고정 높이를 강제하지 않고 메인 기록 시트의 스냅을 **실제 콘텐츠 경계**로 결정한다.
- 최소 높이는 시트 그립·헤더·현재 표시되는 진행바·검증 메시지·안전 영역을 측정해 맞춘다. `--life-sheet-peek-height`로 `.game` 하단 여백을 동기화해, 닫힌 시트 위로 본문을 끝까지 스크롤할 수 있게 한다.
- 중간 높이의 윗변은 포스터+상태 스탯 아래 `.desktop-right > .profile` 시작점에 0.5rem 간격으로 맞춘다. 너무 작은/큰 화면에서는 상단 기준 31~65%로 제한한다. 스크롤 위치가 아닌 문서 좌표에 맞춰 배경 스크롤 중 시트가 움직이지 않는다.
