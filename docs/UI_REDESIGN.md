# UI v3 — 후보 벽보형 플레이어 상태 디자인

## 참고 개념

실제 한국 선거 포스터의 시각적 특징인 큰 이름·기호·슬로건·상징색·인물 영역의 위계를 참고하되, 실제 정당 포스터 문구·로고·사진·배경을 복제하지 않는다.

## 인게임 후보 포스터 (현재 상태)

오래된 설문지형 스탯 창 대신 한눈에 보이는 **가상의 포스터**를 고정 상태로 사용:
- 이름과 상황별 별명('미래의 씨앗', '생활비와 싸우는 대학생', '지역에서 올라온 정치인', '정당에서 쫓겨난 정치인' 등)
- 자동으로 바뀌는 시기별 슬로건
- 당명/단순 추상 심볼/가상 기호
- 얼굴이 보이지 않는 무명 실루엣. 실제 캐릭터 자산은 아직 그리지 않는다.

`data-template`을 `campaign`, `minimal`, `slogan`의 세 가지 값으로 적용해 같은 데이터에서 서로 다른 벽보 구도가 나온다. 정당별 컬러는 전역 CSS 변수 `--party` 한 곳을 기준으로 파생하도록 하고 화면 전반에 반영한다.

입당 이전에는 무소속. 정당에 가입했다 해도 **대선 후보로 지명되기 전에는 공식 후보 기호를 부여하지 않는다.** 가입 선택 팝업의 1~5번은 허구 정당을 구별하는 UI용 번호다.

## 프로필 및 타임라인

- 포스터 옆/아래에 짧은 토큰으로만 학력·직업·활동·정당 상태를 표시한다.
- 자세한 이력은 별도의 인생기록 다이얼로그로 이동.
- 2차원 정치성향을 쉬운 축(분배↔시장, 변화↔안정)으로 시각화, 정당 소속 시에는 조직 신뢰도를 표시.
- 반응형: 데스크톱은 포스터와 보드 2열, 모바일은 가로로 압축한 낮은 포스터를 먼저 보여주고 이벤트/선택 카드 2열 구성을 사용한다.

## 한방 선택 전용 모달

- 유치원 활동 계획, 중학교 탐색, 고교 진학 지망서, 대학 원서, 대학원·진로, 직업군 선택, 정치 진출 서류, 국회의원/대선 경선 참가 명부, 공약·유세 문서.
- 입당은 다른 선택지와 달리 기호 번호·허구 로고·당 색·슬로건이 들어간 가상의 투표지 형태.
- 모든 버튼은 실제 행동과 연결되고 조건이 맞지 않으면 다음 이벤트로 진행하지 않는다.

## 향후 그림 자산 교체 계획 (이번 버전에는 미포함)

8개의 기본 캐릭터 모델을 플레이어마다 하나 배정하고, 각 모델별 아동·청소년·청년·중년·노년의 반측면 이미지 파일을 제작할 계획.
현재 `state.actor`가 0–7 캐릭터 모델 ID를 저장한다. 아직 외부 이미지 파일이나 인물 PNG·SVG가 없으므로 CSS/내장 SVG의 **익명 그림자 실루엣만 사용**한다. 미래 버전은 이 슬롯을 통해 캐릭터 이미지를 교체하고, 기존 나이·이름·정당 UI를 그대로 사용하면 된다.

## 엔딩 포스터

게임 중 상태 포스터는 정보를 빠르게 읽기 위한 간결한 벽보지만, **엔딩은 슬로건·결말 자체가 주인공인 대형 포스터**가 된다. Canvas로 PNG를 로컬 저장하며 서버 업로드를 하지 않는다.

## 차기 스탯 토큰 디자인 논의안 (2026-10-19, 미확정)

> 아래는 제공된 신규 논의를 정리한 **향후 UI 방향**이다. 위쪽의 UI v3 설계 및 현행 `index.html`·`style.css`에 이미 구현된 기능으로 간주하지 않는다. 스탯의 뜻과 전환 시점은 [STATS.md](./STATS.md) 참조.

### 표시 형식을 스탯 종류에 맞추기

- **수치형**: 정신부담, 건강, 성적/경력, 말빨, 지지도. 모든 종류를 동일한 게이지로 강제하지 않는다.
- **방향형**: 정치 성향은 좌 ↔ 우 축 위에 현재 위치를 표시하는 전용 UI를 사용한다. '중도 좌파'처럼 읽기 쉬운 언어로 보조할 수 있다.
- **금액형**: 재산과 상황별 용돈/수입은 화폐 단위를 사용한다.

### SVG 상태/변동 토큰

- 사용자가 만든 시연의 **작고 둥근 알약형**을 기준으로 차분한 배경과 명확한 텍스트를 유지한다.
- SVG 아이콘은 크기, 선 두께, 둥근 끝·연결 형태를 통일한다.
- 아이콘/토큰 색상은 **증감 부호가 아니라 플레이 의미**에 따라 결정한다.
  - 예: '정신부담 +10'과 '건강 −10'은 모두 부정적인 변화이므로 부정적 변화 컬러.
  - '성적 +10', '재산 −1억' 같은 변동 표시는 수치 변화 토큰으로 독립적으로 렌더한다.
- 제시된 숫자(예: 정신부담 12, 건강 91, 성적 68, 말빨 37, 지지도 24%, 재산 3,250만)는 **시각 배치 시연용 임시 수치**이며 기본값/밸런스가 아니다.

### 시기별 노출

- 유년기·학창 시절: 정신부담, 건강, 성적, 말빨, 재산.
- 성인·직장인: 정신부담, 건강, 경력, 말빨, 재산.
- 정치 입문 이후: 지지도와 정치 성향 추가.
- 용돈/수입: 평소 숨기고 경제 사건 및 재산 변동 시 공개.
- 정치 성향 UI: 입당 이전에는 영역 자체를 감추고 입당 시 노출하는 안.

### 이전 설계와의 차이

v3는 **2차원 정치 스펙트럼** 및 기존 능력치를 상정했다. 신규 논의는 **좌우 1차원 정치 성향 + 8개 스탯** 안이다. 두 안을 임의로 합치지 않고 후속 협의에서 확정한다.
