# 조사 기록 — 국민의 부름

확인일: 2026-10-19
범위: 한국 교육·직업·선거제도를 참고한 웹 게임 프로토타입. 출생 연도·미래 선거 일정·가상의 정당은 창작.

## 1. 검증한 법적 사실

| 사실 | 조사 결과 | 반영 |
|---|---|---|
| 대통령 피선거권 | 선거일 현재 5년 이상 국내에 거주하는 40세 이상의 대한민국 국민. 공직선거법 제16조 제1항 | 플레이어는 국내 거주로 가정하며 나이 40세부터 대권 경로 활성화 |

## 2. 교육 제도 및 게임 선택지

실제 고등학교 유형:
- **일반고**: 폭넓은 일반 교육과정
- **특수목적고**: 특정 분야에 맞춘 교육
- **특성화고**: 직업교육·대안교육 포함
- **자율고**: 자율형 공립고·자율형 사립고

교육부의 고입정보포털에서도 고등학교 유형을 이러한 방식으로 구분한다. 프로토타입에서 '특목고·자율고'를 하나의 선택지로 합친 것은 단순화이며 제도상 동일한 유형이 **아니다**. '검정고시'는 고등학교 유형이 아니라 학력 인정 제도/별도 경로다.

진학 후에도 고등교육·전문대학·직업훈련·취업·재수 등의 경로를 제공한다. 수도권·지역대학, 직업훈련 등은 인맥과 자금/학업 자원의 **게임상 상충 관계**일 뿐 실제 학력이나 개인 역량의 서열이 아니다.

실제 특정 학교의 평가를 숫자로 재현하지 않는다. 학교의 실명·순위표·진학률 등은 의도적으로 게임에 넣지 않았다. 실제 제도·자료와 시뮬레이션의 균형값을 혼동하지 않는 것이 중요하다.

## 3. 정치 진입 경로 모델

단일 정답 루트를 만들지 않는다.

가능한 시나리오 예:
- 학생회/지역 활동 → 시민 활동 → 지역 정치 → 정당 경선 → 대통령 후보
- 직장·사업 실적 → 정책 자문 → 공직선거 → 대권 시도
- 행정·전문직 경험 → 정책 집필 → 캠프 전략가 → 정당 진입
- 1인 미디어 → 인지도 확보 → 정계 입문 (높은 검증 리스크)
- 정계 미진입 → 직장인/사업가/미디어/평범한 생활 결말

이는 경력 경로의 **창작 모형**이지 실제 대통령의 이력 통계를 반영한 일반화가 아니다.

## 4. 풍자·정치적 비편향

- '국민의 부름'은 허구의 국가 정치 무대에서 진행된다.
- 현실 정당명·로고·특정 정치인·가족·실제 스캔들 사실관계·선거 결과를 사용하지 않는다.
- 5개 정당의 기호는 1~5 **가상 참가 번호**이고 색상·로고·슬로건은 독립적으로 제작한다.
- 각 성향에 고유한 단점·장점이 있다. 보수·진보·급진·질서·실용 어느 노선도 자동으로 범죄나 성공으로 연결하지 않는다.
- 형사 유죄 결말은 이념이 아니라 플레이어 자신의 부당한 행위 및 누적 책임과 연결된다.
- 법적 면책을 보장하는 문구는 쓰지 않는다. 공개 전 명예훼손/저작권/선거 관련 법률 검토가 필요할 수 있다.

## 5. 게임과 실제 현실의 차이

| 게임 | 실제 |
|---|---|
| 1번부터 5번까지 고정 | 실제 선거 기호는 선관위 법정 규칙에 의해 선거마다 결정 |
| 인생의 한 해가 한 장면 | 학업·직업·정치는 긴 기간과 복잡한 조건 |
| 지표 다섯 개로 선거 계산 | 실제 선거는 유권자의 자유로운 판단과 다수 요인으로 결정 |
| 당내 경선과 선거가 빠르게 전개 | 후보 등록, 공천, 선거운동, 정책 실현에 엄격한 제도와 법률 존재 |
| 무소속 출마 가능성을 자금으로 단순화 | 실제 등록 자격, 추천인, 기탁금 등 법적 조건 다수 |

이 게임의 연도는 2026년을 시작점으로 하는 가상 미래이며 실제 선거 일정을 뜻하지 않는다.
