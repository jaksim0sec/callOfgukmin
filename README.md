# Korean DEPPANG — 대통령 되는 법

가상 대한민국에서 태어나 인생을 선택하며 대통령을 꿈꾸는 5~10분짜리 풍자형 웹 인생 시뮬레이터.

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages의 저장소 루트로 배포한다. 빌드, API 키, 서버, 회원가입이 필요 없다.

## 특징

- 무작위 출생 배경 및 가정환경, 확률적 결과
- 초등·중등·고등 진학, 대학/직업, 정당 선택과 공직선거
- 선택의 후속 결과, 조건부 선택지, 정치적 위험/기회
- 대통령 당선뿐 아니라 낙선·평범한 인생·논란·은퇴 등 다중 엔딩
- 모바일 지원, 로컬 자동 저장, 결과 카드 PNG

## 자료와 한계

`docs/RESEARCH.md`에는 한국 공직선거법 및 교육 정보의 공식 자료를, `docs/GAME_DESIGN.md`에는 게임 모델과 구현 원칙을 정리했다. 시뮬레이션의 확률·학교 및 정치 스탯은 창작 게임 밸런스이며 실제 개인·지역·학교의 확률이나 평가를 뜻하지 않는다. 모든 정당·정치인·사건은 허구다.

## 라이선스

콘텐츠/코드의 저작권은 저장소 소유자에게 있으며, 외부 원작의 코드나 이미지를 복제하지 않았다.
