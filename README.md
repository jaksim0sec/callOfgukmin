# 국민의 부름 — THE PEOPLE CALL

**대통령이 될 상인가? 아니면 그냥 백수로 살 상인가?**

한국의 교육·직장·정당·선거를 풍자한 5~10분 웹 인생 시뮬레이터. 인생의 선택이 누적되어 후보 지명, 낙선, 당선 또는 다른 엔딩으로 이어지는 게임.

## 플레이

- `index.html`을 브라우저로 열거나 GitHub Pages로 공개하면 실행 가능
- 회원가입·서버·빌드 절차 없음
- 1~4 숫자키로 선택, 결과 확인 후 Enter로 계속 진행
- 이어 하기는 브라우저 로컬 저장소에서 자동 복구
- 최종 결과 카드 PNG 다운로드 및 모바일 공유
- 가상의 정당 5개를 투표용지 UI에서 선택

## 이번 범위

**대통령 당선 발표까지** 구현. 임기 수행, 탄핵, 재선은 포함하지 않음. 중도에 정치 진로를 접거나 경선에 탈락해도 개별 엔딩으로 정리.

## 구조

- `index.html`: 시맨틱 화면 및 상태 영역
- `style.css`: 신문·기록부·투표용지 스타일, 반응형 레이아웃
- `game.js`: 분기/상태/확률/기록/저장/PNG 내보내기
- `docs/RESEARCH.md`: 한국 교육·선거 제도에 관한 자료, 출처 및 창작 구분
- `docs/GAME_DESIGN.md`: 액트·정당·게임 밸런스 방향
- `docs/QUALITY.md`: 점검 사항 및 범위 한계

실제 법률과 다른 부분(투표용지 번호, 미래 연도, 확률 및 정치 시나리오)은 **가상 게임 규칙**이다. 어떤 정당, 정치인, 선거 또는 사건도 실제로 재현하지 않으며, 개인의 출신 학교나 지역을 평가하지 않는다.
