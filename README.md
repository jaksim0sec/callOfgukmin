# 국민의 부름 — UI 기반 시연

현재 배포본은 **게임 진행을 잠시 비활성화한 UI 기반 프로토타입**입니다. 생애·사건·선거 시스템은 아직 기획 중이며, 코드에 미완성 규칙을 임의로 고정하지 않습니다.

## 현재 작동하는 기능

- **랜덤 인물 생성**: 출생 시 이름·출생 지역·가정 배경·기본 프로필 생성.
- **로컬 저장·불러오기·새 인물 생성**: 전용 키 `callOfgukmin__ui__v1` 사용.
- **포스터 DOM**: 정당색, 이름, 상태 문구, 이미지 슬롯. 기존 `js/poster.js` 공통 렌더러 사용.
- **학교 지원 서류·정당 투표지 미리보기**: 카드 선택·확인은 작동하지만 나이·스탯·소속은 변하지 않음.
- **PC 레이아웃**: 왼쪽 위 인물 포스터, 왼쪽 아래 나이·학력·특성, 오른쪽 위 능력치, 오른쪽 아래 인생 기록과 UI 미리보기.
- **모바일 레이아웃**: 포스터·상태표 가로 2열, 능력치 아래, 인생 기록은 닫히지 않는 고정 바텀시트.

## 현재 실행하지 않는 기능

사건 생성, 인생 시간 진행, 성장 선택, 진학·취업의 실제 결과, 입당과 당내 관계, 선거·경선, 엔딩, 결과 카드 PNG 생성은 활성 게임 코드에서 제외했습니다. **기획 문서 자체는 삭제하지 않았습니다.**

차기 스탯 8종은 아직 미확정입니다. 화면의 정신부담 0, 건강 100, 성적 0, 개인 재산 0은 인물 생성 상태용 샘플이며, 말빨·지지도·정치 성향은 미정/미활성입니다.

기존 플레이 저장 키 `callOfgukmin__playable__v1`은 삭제하거나 변환하지 않습니다. 기존 게임 코드는 Git 커밋 기록에서 복구할 수 있습니다.

## 파일

- `index.html`: 게임 화면·UI 팝업 구조
- `css/style.css`: PC 2×2, 모바일 바텀시트, 포스터/서류/투표지 스타일
- `js/poster.js`: 공통 포스터 DOM create/update API
- `js/game.js`: 현재는 인물 생성·데이터 관리·UI 렌더링만 담당
- `tests/smoke.mjs`: 정적 참조, 문법, DOM, 게임 진행 코드 제거 검사
