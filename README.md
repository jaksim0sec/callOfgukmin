# 국민의 부름

**한 표보다 무거운 한 생.** 한국 사회를 풍자하는 5~10분짜리 선택형 인생·정치 시뮬레이션.

> v3 — 설문지 스타일에서 게임 보드와 생애 결정 시스템으로 재설계

## 실행

정적 웹 앱이므로 저장소 루트의 `index.html`을 열거나 GitHub Pages에서 호스팅. 빌드·백엔드·계정·API 키 없음.

## 게임 화면

- **후보 포스터 형태의 현재 상태**: 시기별 별명(예: 미래의 씨앗), 이름, 가상 정당, 선거 기호. 3개의 벽보 구도를 CSS로 전환
- **익명 실루엣**: 캐릭터 8종과 성장 단계별 일러스트는 추후 별도 제작하여 교체 예정; 현재 실제 인물 사진·원작 캐릭터 이미지를 사용하지 않음
- **짧은 프로필 토큰**: 고등학교, 대학, 대학원, 직업, 정당 소속
- **별도 인생 연대기**: 화면의 '인생기록' 버튼에서 볼 수 있음
- **정치 스펙트럼**: 분배↔시장, 변화↔안정 + 소속당 신뢰 지표

## 플레이 방법

1. 랜덤 출생 배경에서 시작, 이름만 선택할 수 있음.
2. 각 인생 단계에서 1~2번의 **일상 선택** 수행. 사건은 매 판 섞여 나오며 결과가 후일에 돌아올 수 있음.
3. 일상 시간이 지나면 **한방 선택**이 열림. 고교 원서, 대학·대학원·직업 선택, 정치 입문, 투표용지풍 입당, 선거와 공약 등은 각각 상황에 맞는 서류형 팝업.
4. 정당에 들어간 이후 노선과 반대되는 발언을 반복하면 소속당 신뢰가 하락하고, 심하면 제명될 수 있음.
5. 무조건 대통령이 되는 건 아님. 비정치 인생, 사업·방송, 경선 탈락, 제명, 법적 책임, 대선 낙선, 당선 엔딩.
6. 최종 결과 포스터 PNG 저장 또는 텍스트 공유. 대통령 당선 시점에서 게임 종료. 국정 운영·탄핵·재선은 미구현.

## 코드 구조

- `index.html`: 장면·포스터·게임 보드·모달·결과 UI
- `style.css`: CSS 변수 기반 정당 테마, 포스터 3종, 데스크톱/모바일 레이아웃
- `game.js`: 랜덤·게임 상태·이벤트·일상/한방 선택·정치 스펙트럼·유죄/제명·대선·결과 이미지
- `docs/RESEARCH.md`: 교육/공직선거 제도 조사
- `docs/GAME_DESIGN.md`: 게임 루프와 밸런스·분기 정의
- `docs/UI_REDESIGN.md`: 포스터·토큰·캐릭터 아트 교체 가이드
- `docs/QUALITY.md`: 자동 테스트 및 검증 한계

브라우저 로컬 저장소 키 `callofgukmin-v3`. 이전 v2 세이브와 분리하며 서버로 개인정보를 전송하지 않음.

## 주의

모든 정당·정치인·사건·선거 결과는 가상 설정이며, 실제 선거의 여론 조사나 투표 수치가 아닙니다. 어떤 지역·학교·집단의 실제 가치를 판정하지 않습니다. 실제 정치 포스터·로고·사진을 복제하지 않았습니다.
