# 국민의 부름 — UI 기반 시연

현재 배포본은 **게임 진행을 잠시 비활성화한 인물·화면 UI 기반**이다. 출생·선택·선거·엔딩 시스템은 아직 만들지 않았다. 기존 인생 진행 세이브를 삭제하거나 재활성화하지 않는다.

## 화면

- **대기** (`html/waiting.html`): 이름·출생 배경·포스터, 새 인물 생성, 인게임 진입, 결과 화면 미리보기.
- **인게임** (`html/game.html`): PC 2열 / 모바일 포스터·속성 정보 + 항상 열린 인생 기록 바텀시트. 속성 스탯은 왼쪽, 상태 스탯·특성 토큰은 오른쪽.
- **결과** (`html/result.html`): 별도 결과 레이아웃. 현재는 종료 판정이 없는 **미리보기**만 가능.
- `index.html`은 GitHub Pages용 단일 진입 문서다. `js/boot.js`가 각 HTML 조각을 필요할 때 불러와 **한 번에 한 화면만** 표시한다.

## UI 기반 기능

- 이름·지역·가정 배경 무작위 생성, 현행 UI용 키 `callOfgukmin__ui__v1`에 로컬 저장/복원, 새 인물 생성.
- 기존 공통 `GukminPoster.create/update`로 각 화면에서 인물 포스터 표시.
- 속성 스탯의 출생지·집안·현재 역할 표시, 학력은 **교표형 SVG 아이콘+학교명 알약 토큰**으로 누적 가능. 재학 중만 강조 테두리/배경을 적용하고 졸업은 일반 토큰으로 보존.
- 상태 스탯은 생애 단계에 따라 동적으로 활성 목록 표시(0세는 기본 3개). 아래에 특성을 **SVG 라인 아이콘+이름 토큰**으로 표시. 특성의 실제 버프·디버프 계산은 아직 없음.
- 진학 서류·가상 정당 투표지 선택 UI 미리보기. 선택해도 인물 데이터·시간·정치 상태를 변경하지 않는다.

## 개발

```sh
node tests/smoke.mjs
python3 -m http.server 8000
```

정적 HTML 조각은 HTTP 서버에서 `fetch`로 로드한다. `file://`에서 직접 열면 작동하지 않을 수 있다.
