# 국민의 부름 — 시연 작동판

네가 만든 **초경량 HTML 시연**과 그것을 다듬은 버전을 기준으로, 시연의 레이아웃을 거의 그대로 유지하면서 실제로 한 판을 진행할 수 있도록 연결한 체크포인트입니다.

## 플레이

- 진입점: 저장소 루트의 `index.html`. 외부 빌드 도구 없이 `index.html`, `style.css`, `game.js`만으로 동작.
- 첫 장면은 **0살 출생**. 인생 기록에서 상황을 읽고 `시간을 넘긴다` 또는 `결정의 순간`을 눌러 진행.
- **학교 선택**: 서류 느낌의 블러 배경/슬라이드 업 선택 팝업, 교표, 조건, 능력치 변경 토큰. 휘문고·병신고·이빨고 등의 학교 설정 및 지원 조건은 **게임 속 창작 수치**.
- **직업 선택**: 명함형. **입당 선택**: 번호, 당명, 상징과 도장이 있는 가상 투표지.
- **선거 진행**: 국회의원 출마/대통령 후보 경선/대선. 실패·낙선·제명·법적 책임 등 여러 결과가 가능.
- 선택에 따른 학력·직업·특성이 인생 기록에 누적. 정당 가입 후 노선과 어긋나는 정치적 발언을 계속하면 당내 신뢰가 떨어질 수 있음.
- 사건 순서는 기본 서사를 유지하되 일부 일상 사건이 판마다 달라짐. 출생 배경도 달라짐.
- 진행은 브라우저 로컬 저장소(`callOfgukmin__playable__v1`)에 자동 저장하며, 상단의 작은 `↻` 버튼으로 초기화.
- 결과가 나오면 **PNG 카드 저장** 및 새 인생 시작 가능.

## 모바일 UI

- 인물 포스터와 학교·특성·능력치 요약을 상단에 간결하게 표시.
- 인생 기록은 **닫히지 않는 하단 고정 바텀시트**. 기록 안에서만 스크롤.
- 인생의 한방 선택은 바텀시트와 **별도의 흐린 배경 모달**. 학교 지원은 아이보리색 서류, 정당 선택은 투표용지 디자인.
- PC는 전체 페이지 스크롤 대신 기록 패널 자체에 스크롤을 적용.
- 캐릭터 이미지는 추후 8개 모델의 성장별 이미지를 연결할 계획이므로 현재는 익명 실루엣으로만 처리.

## 현재 범위 및 다음 논의

이 버전은 **시연을 작동시키는 기준점**입니다. 전체 게임의 완성판이 아닙니다. 핵심 서사는 아직 길이가 제한돼 있고, 사실적 선거 규칙과 복잡한 정치 관계망·직업군·특성 조건 등은 추가 논의가 필요합니다. 후속 작업에서도 네가 만든 UI를 기준으로 개선합니다.

기존 `docs/GAME_DESIGN.md` 및 `docs/UI_REDESIGN.md`는 이전 v3 검토 기록입니다. 현재 구현 범위는 이 README를 기준으로 보세요.

모든 정치적 정당·선거 결과·정치 성향 수치는 풍자 게임의 **허구**이며 실제 정치 정보나 여론조사를 나타내지 않습니다.
