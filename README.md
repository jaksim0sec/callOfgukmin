# 국민의 부름

[게임 시작하기](https://jaksim0sec.github.io/callOfgukmin/html/waiting.html) · [검색 등록 안내](docs/developing/SEO.md)

한국을 배경으로 선택과 누적된 이력에 따라 전개되는 인생·정치 시뮬레이션 게임입니다. **현재 플레이 가능한 범위는 출생부터 고교 졸업·입시/N수, 사회 허브의 대학·병역·취업을 거쳐 정치 입문 준비까지**입니다. 정당 조직·실제 선거·대통령 경로는 아직 구현되지 않았습니다. 학생기 완료·한계 종료 결과와 현재까지의 기록은 결과 화면에서 확인·공유·이미지로 저장할 수 있습니다.

개정 수치·호환·요구별 검증: [학생 생애 개정 검증표](docs/developing/STUDENT_REVISION.md). 재수학원은 가족이 흙0·동1·은2·금4회, 다이아는30세 이전까지 지원합니다. 개인 재산은 차감하지 않으며 지원이 끝나면 독학으로 이어집니다. 중간 사회 진출 기회, 장기 준비의 경력 공백과28세 경고를 반영하고30세까지 입시만 이어가면 백수 엔딩입니다.

한국식 세는나이를 사용합니다. 태어날 때1살, 초등학교 입학8살, 중학교14살, 고등학교17살, 수능19살·졸업20살입니다. 기존 저장의 나이도 한 번 보정하며 선택·재산·진행 기록은 유지합니다.

## 현재 구현된 플레이

- **인물 생성과 성장**: 출생 전 이름 입력·출생지·집안/재력, 유년기~초·중·고 사건, 과거 선택과 활동 경험에 따른 조건 분기
- **자원과 영향**: 학업·관계·압박(`stress`, 0~25)·정신병(`illness`, 0~5)·재산·특성의 손익. 재산과 턴별 용돈 지급량은 별개
- **학교와 시험**: 게임 수치 기반 중학교 평가, 고교 유형별 지원/활동, 고교 내신·모의고사·최종 수능 성적표 연출
- **대입과 진로**: 최종 내신 제출, 수시/정시 경로, 대학 원서 한 건의 게임 판정, 합격/불합격, 사회 진출 또는 종료 경계까지 반복하는 입시 재도전. 이후 사회 허브로 연결
- **사회 허브**: 2·3·4년제 학업과 등록금/대출·휴복학·졸업, 병역판정/군별 복무와 학업 지연, 취업 준비·지원/실패·근무·전환·자영업, 선택적 정치 입문 준비. [범위와 규칙](docs/developing/SOCIETY.md)
- **일상 선택**: 인생 기록에서 직접 열거나 5초 후 자동으로 나타나는 모눈종이 선택 시트. 확정 뒤 **같은 종이**에서 결과·수치 변화·획득 특성을 확인하고 **`보상 받기`** 로 닫아 다음 이야기 진행. 화면별 보상은 공통 알약 토큰 사용
- **한방 선택**: 시험·학교/대학 지원서 및 진로·성적 결과 UI. 접어도 선택을 유지하고 다시 열 수 있음
- **화면/저장**: PC 2열, 모바일의 닫히지 않는 인생 기록 시트, 선택·정산·진로 이력 저장 및 새 인물 재시작

실제 학교·대학 이름을 예시로 사용하더라도 **게임 난도·등급 환산·합격 판정·비용은 실제 입학 기준이나 공식 성적이 아닙니다.** 지원 학교·진로도 현실 제도 전체를 재현하지 않습니다.

## 실행

별도 빌드나 백엔드가 없는 정적 HTML/CSS/JavaScript 프로젝트입니다. GitHub Pages는 루트 `index.html`을 통해 `html/waiting.html`로 진입합니다.

```sh
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/ 접속
```

최근 개정: 건강 폐지·정신병/관계 한 줄, 유년기 특성 중심, 선택적 회복과 정신병 한계 종료, 상담 가독성·개표 연출·시험 전환·수능 응시 전 표기 개선. 자산 버전 `society-20261022`. 기본 수치 스탯은25점 정수이며 유년기 보상은 확정 후 공개합니다. 정신병 경고와 구매 간격이 있는 편의점 시제품을 포함합니다.

## PWA·오프라인

제공받은 국민의 부름 로고를 파비콘·Apple 홈 화면·PWA 앱 아이콘으로 적용했습니다. HTTPS에서 한 번 접속해 오프라인 준비가 끝나면 대기·게임·결과 화면을 네트워크 없이 사용할 수 있습니다. 지원 브라우저의 **앱 설치 / 홈 화면에 추가** 메뉴를 이용하세요. 오프라인에서는 외부 웹 글꼴 대신 기본 글꼴을 사용하며 기존 인생 저장은 유지됩니다.

## 개발 검증

```sh
node tests/smoke.mjs
node --test tests/systems.mjs
# Playwright와 Chromium이 설치된 환경에서
node tests/browser.mjs
node tests/experience.mjs
node tests/pwa.mjs
```

- `smoke`: 정적 파일·스크립트 참조/구문·기본 DOM 계약
- `pwa`: 설치 가능 판정·PC/모바일 오프라인 플레이/결과 이미지·저장 복구·캐시 업데이트
- `systems`: 정산·조건·턴·저장·선택 상태·생애 시나리오
- `browser` / `experience`: Chromium의 시트 제스처·보상·진학 화면·저장 복구·화면 조작 경로
- CI는 **소스 또는 테스트 변경 시** 위 검증 작업을 실행하며 스크린샷을 남깁니다. 현재 워크플로는 **문서만 바꾼 커밋에는 실행되지 않습니다.** Safari·삼성 인터넷 실기기와 저사양 성능은 별도 확인이 필요합니다.

현재 세이브 키는 `callOfgukmin__ui__v1`입니다. 이전 시연 키 `callOfgukmin__playable__v1`은 건드리지 않습니다. 게임 주소의 `?systems=1`은 개발 검증 도구 전용입니다.
